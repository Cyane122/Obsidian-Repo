2 (i). Neural Network
A neural network is a model that learns patterns from data.
It is made of connected neurons arranged in layers.
Each layer processes information and passes it to the next layer.
During training, the network learns how strongly neurons should be connected.
Three Main Parts
Input Layer → receives the data
Hidden Layers → learn patterns
Output Layer → produces the result
A neural network learns to turn input data into useful predictions.
11

=== SLIDE 12 ===
2 (ii). The Artificial Neuron
A neuron is the basic building block of a neural network.
It receives inputs, gives each input a weight, adds a bias, and produces an output.
Artificial Neuron is also called a Perceptron.
Main Components
Inputs (x) → information coming in
Weights (w) → importance given to each input
Bias (b) → helps adjust the result
Weighted Sum → combines the inputs
Output (z) → result passed to the next layer
Equation
A neuron combines information from its inputs to produce an output.

=== SLIDE 27 ===
Loss Function:
A loss function measures the difference between the predicted output and the actual target.
It helps the neural network adjust weights during training to minimize errors.
Cost Function:
The cost function is the average of the loss function over the entire dataset.
It provides a single scalar value to optimize the model.
Types of Loss Functions in Neural Networks

=== SLIDE 28 ===
Backpropagation is an algorithm used to reduce the loss by adjusting the weights based on the error from the output layer to the input layer.
3 (iii). Backpropagation – Intuition
28
Rumelhart, Hinton & Williams (1986)
Learning Representations by Back-Propagating Errors
Gradient of Loss: Shows how much the loss changes when a model parameter changes, and in which direction.
Gradient Descent: Uses the gradient to update the model parameters step by step to reduce the loss.
Partial Derivatives: Measure how the loss changes with respect to one parameter at a time, while keeping the others fixed.
Key Steps:
Forward Pass → Pass the input through the network to get the output.
Calculate Loss → Compare the predicted output with the actual output.
Calculate Gradients → Find how each weight affects the loss using the chain rule.
Propagate Backward → Send the gradients backward through the layers.
Update Weights → Adjust the weights using gradient descent.
Repeat → Continue this process to reduce the loss.
Important Notes
Backpropagation adjusts weights using partial derivatives of the loss.
It propagates the error backward through the network to efficiently update the weights.

Initialize weights & biases

Backpropagation – Calculate gradients to adjust parameters.
Update weights using gradient descent
Repeat until convergence
Evaluate and adjust hyperparameters

=== SLIDE 34 ===
Representation learning is when a neural network learns how to describe data in a useful way by itself.
Instead of humans manually choosing all the important features, the network discovers them from the data.
We do not manually tell the network to learn features. It discovers them during training.
4. Representation Learning
34
The network learns what information is important for the task.
Why is it important?
Representation learning helps neural networks:
automatically learn useful features
work with complex data
find similarities between data
reduce the need for manual feature engineering

Latent Space
Latent Space: A learned space where embeddings are organized based on their meaning and relationships.
Similar objects → placed closer together.
Different objects → placed farther apart.
Embedding
Embedding: A numerical representation of an object that captures its meaning or important features.
Example: Cat → [0.8, 0.3, 0.4, …]
