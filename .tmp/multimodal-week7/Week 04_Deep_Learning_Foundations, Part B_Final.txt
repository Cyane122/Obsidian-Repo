1. Multimodal Embeddings
3
Multimodal means working with more than one type of data, such as:
Images
Text
Audio
Video
A multimodal embedding converts these different types of data into numerical vectors so that their meaning can be compared.
Main idea
Different modalities can be converted into representations that live in a shared space.
Multimodal embeddings connect different types of data through their meaning.

=== SLIDE 4 ===
A common representation space is a shared space where different types of data—such as images, text, and audio—are represented in a way that allows their meanings to be compared.
1. Multimodal Embeddings
4
Points that are semantically similar (same meaning) are close together, even if they came from different modalities.
Key Points
Different modalities are converted into embeddings.
The embeddings are mapped into the same shared space.
Data with similar meanings are placed close together.
Data with different meanings are placed farther apart.
This allows the model to compare information across different modalities.

=== SLIDE 6 ===
2. Convolutional Neural Networks (CNNs)
6
Important Parameters
1. Kernel Size
Determines the size of the filter.
Common examples: 3×3, 5×5
Smaller kernels capture fine details; larger kernels capture more context.
2. Stride
Controls how far the filter moves at each step.
Stride = 1: moves one pixel at a time.
3. Padding
Adds pixels, usually zeros, around the image.
Helps control the output's spatial dimensions.
4. Number of Filters
Multiple filters learn different patterns.
Each filter produces a separate feature map.
Key Takeaway
Convolution allows CNNs to automatically detect important visual patterns, which are represented as feature maps and used by deeper layers to recognize complex objects.

3. (i) Max Pooling
19
Feature Map
Max Pooling: is a down sampling (subsampling) operation used in Convolutional Neural Networks (CNNs) to reduce the spatial dimensions (width and height) of feature maps while retaining the most dominant features.
Primary Purposes
Dimensionality Reduction: Shrinks feature map size to reduce computation and memory usage.
Translation Invariance: Keeps features detectable despite minor shifts or distortions.
Overfitting Prevention: Reduces spatial resolution to prevent memorizing pixel-level noise.

3. (ii) Average pooling
24
Average pooling:  is a down sampling operation that reduces the spatial dimensions (width and height) of a feature map by calculating the arithmetic mean of values within a sliding window.
Core Concept: Unlike Max Pooling (which selects the highest value in a region), Average Pooling calculates the average intensity across all pixels inside the pool window.
Key Properties
Smooth Feature Extraction: Blurs extreme activations, keeping overall background context rather than just sharp edges or maximum spikes.
Parameter-Free: Operates deterministically (fixed rule) without any trainable weights or biases.

=== SLIDE 33 ===
4. LeNet-5 (Example)
33
LeNet-5 Architecture Overview
Input Image: Processing a handwritten digit input (7).
Feature Extraction (Convolutions & Subsampling): Alternating convolutional and pooling layers systematically down sample spatial resolution while extracting hierarchical features (edges, curves, loops).
Feature Maps: Intermediate feature maps display active activations responding to distinct patterns of the input digit.
Fully Connected Layers & Classification: Extracted features are flattened and passed through dense layers to output class probabilities for digits 0–9.
LeNet-5 is an early convolutional neural network designed to recognize handwritten digits.
