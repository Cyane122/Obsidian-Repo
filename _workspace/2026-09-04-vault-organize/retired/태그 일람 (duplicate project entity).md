# 개요

`태그 일람`은 개인 학술 Wiki에서 사용할 canonical tag의 이름과 범위를 정의한 `90 Meta/태그 일람.md` 문서다. 새 태그를 즉석에서 만드는 대신 이 문서를 단일 기준으로 사용한다.

# 분류축

- `domain/*`: machine-learning, nlp, multimodal, recommender-systems, privacy-and-safety
- `task/*`: language-modeling, recommendation, text-rewriting 등
- `method/*`: attention, transformer, collaborative-filtering 등
- `theme/*`: evaluation, generalization, computational-efficiency 등

# Legacy 변환

`#NLP → #domain/nlp`, `#RNNs → #method/recurrent-neural-network`, `#MCTS → #method/tree-search`, `#matrix_factorization → #method/matrix-factorization` 같은 변환표를 보유한다. 모델·논문 고유명은 태그가 아니라 wikilink로 남긴다.
