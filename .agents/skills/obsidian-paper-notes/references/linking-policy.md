# Linking policy

위키링크는 단어 장식이 아니라 독자가 따라갈 탐색 경로다. 링크 수를 목표로 삼지 않는다.

## 링크할 때

다음 중 하나에 해당하면 링크 후보로 본다.

- 대상이 canonical 문서로 이미 존재한다.
- 독자가 현재 문서를 이해하려면 별도 정의나 연구 흐름이 필요하다.
- paper와 paper-origin concept처럼 출처 관계 자체가 지식이다.
- 여러 문서에서 반복되어 독립 문서로 발전할 가능성이 높다.

후보를 찾은 뒤 파일명, `title`, `aliases`, 본문 범위를 확인한다. semantic search만으로 대상을 확정하지 않는다.

## 링크 방식

- 같은 섹션에서는 첫 번째 자연스러운 언급에만 링크한다.
- 표시 이름이 문장에 더 자연스러우면 `[[Canonical Name|표시 이름]]`을 쓴다.
- basename이 겹치면 가장 짧은 구분 경로를 사용한다.
- PDF의 특정 근거는 `[[40 Sources/...pdf#page=N]]`으로 연결한다.
- comparison과 synthesis의 주요 판단에는 근거가 되는 paper 또는 concept 링크를 가까이 둔다.

코드 블록, 수식, YAML의 일반 문자열, 직접 인용문 안에는 자동으로 링크를 넣지 않는다. 아직 없는 문서는 stub을 자동 생성하지 않고 `needs review`에 후보 이름과 이유를 남긴다.

## 양방향 탐색

새 문서가 기존 연구 흐름에 들어가면 관련 map에서 발견할 수 있어야 한다. 다만 모든 생성 작업이 map 수정으로 이어지는 것은 아니다. 새 자료가 연구의 위치, 분기, 비교 축, 종합 결론을 바꿀 때만 map·comparison·synthesis 갱신을 제안하거나 요청 범위 안에서 실행한다.

자동 cross-link는 사용하지 않는다. 링크를 추가한 뒤 실제 대상, alias 충돌, 같은 섹션의 반복 링크, 고아 문서 여부를 확인한다.
