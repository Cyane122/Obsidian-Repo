# Folder layout

폴더 구조와 문서 유형의 단일 기준은 저장소의 `90 Meta/Vault Schema.md`다. 이 파일은 이전 버전의 skill 호출과 링크를 깨뜨리지 않기 위한 호환용 안내만 남긴다.

- 새 문서를 배치할 때는 Vault Schema의 `canonical home`을 따른다.
- `comparison`은 `35 Comparisons/`, `synthesis`는 `37 Syntheses/`에 둔다.
- `30 Maps/Comparisons/`와 `30 Maps/Syntheses/`의 기존 파일은 legacy migration 후보이며 자동 이동하지 않는다.
- 논문 PDF의 세부 배치는 [pdf-library.md](pdf-library.md)를 따른다.
- 승인된 구조 정리는 [legacy-migration.md](legacy-migration.md)의 순서와 안전 장치를 따른다.

Skill reference나 template의 예시가 Vault Schema와 다르면 Vault Schema를 우선한다.
