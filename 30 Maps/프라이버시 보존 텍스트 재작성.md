# 흐름 요약

텍스트 프라이버시는 식별자를 지우는 것만으로 해결되지 않는다. 문맥과 문체에서 민감 속성을 추론할 수 있으므로, 최근 연구는 의미·자연스러움·프라이버시를 함께 측정하고 LLM 재작성 과정 자체를 제어한다.

# 연구 흐름

1. [[Anonymity at Risk - Assessing Re-Identification Capabilities of Large Language Models in Court Decisions]] (2024)
   - 실제 법원 판결문과 통제된 Wikipedia 자료로 LLM 재식별 위험을 측정했다.
   - 데이터의 공개 단서와 평가 설정에 따라 위험이 크게 달라진다.
2. [[NAP² - A Benchmark for Naturalness and Privacy-Preserving Text Rewriting by Learning from Human]] (2025)
   - 삭제와 추상화라는 인간 재작성 전략을 데이터셋과 평가 문제로 정식화했다.
3. [[Zero-Shot Privacy-Aware Text Rewriting via Iterative Tree Search]] (2025)
   - reward-guided tree search로 민감 구간을 단계적으로 고쳐 단일 재작성의 불안정성을 줄였다.
4. [[IncogniText - Privacy-enhancing Conditional Text Anonymization via LLM-based Private Attribute Randomization]] (2025)
   - 민감 속성을 단순히 숨기는 대신 잘못된 값으로 추론되도록 조건부 재작성하고, on-device 모델로 증류했다.
