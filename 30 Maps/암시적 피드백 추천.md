# 흐름 요약

암시적 피드백에서는 관측하지 않은 항목을 곧바로 싫어한 항목으로 볼 수 없다. WR-MF는 선호와 신뢰도를 분리해 모든 사용자-항목 쌍을 weighted regression으로 학습하고, BPR은 관측 항목이 미관측 항목보다 위에 오도록 상대 순위를 직접 학습한다.

# 연구 흐름

1. [[Collaborative Filtering for Implicit Feedback Datasets]] (2008)
   - binary preference와 관측 강도 기반 confidence를 분리했다.
   - ALS로 전체 행렬을 효율적으로 사용하지만 ranking metric을 직접 최적화하지 않는다.
2. [[BPR - Bayesian Personalized Ranking from Implicit Feedback]] (2009)
   - 사용자별 positive-negative 항목 쌍의 순위를 최적화했다.
   - 미관측 항목의 노출 편향과 샘플링 편향은 남는다.
