# 학교 수업 정리

강의의 시간 순서를 보존하면서, 수업에서 반복되는 논문·모델·평가 용어를 기존 학술 지식 위키와 연결하는 공간이다.

## 수업 목록

- [[파이썬 텍스트 분석과 LLM, RAG 애플리케이션 개발]]: 텍스트 전처리에서 LangGraph까지 이어지는 NLP·LLM 애플리케이션 개발 과정
- [[데이터 분석 실전반 - 추천 시스템]]: 비개인화 추천, 행렬 분해, Two-Stage 추천 시스템 과정

## 정리 원칙

1. 주차 노트는 강의 흐름과 실습 맥락을 보존한다.
2. 여러 주차에서 재사용되는 개념은 `20 Concepts/`의 canonical 문서로 연결한다.
3. 강의에서만 다룬 도구·API 용어는 과목별 용어 사전에 먼저 정리한다.
4. 원문에 없는 성능 수치나 결론은 추가하지 않는다.
5. 수업 자료와 개인 메모를 구분하고 기존 메모는 삭제하지 않는다.

## 빠른 탐색

- 과목별 전체 흐름: 각 과목의 동명 허브 노트
- 정의 중심 복습: 과목별 `전체 용어 정리`
- 실습 순서 복습: 주차별 노트
- 연구 배경 확인: `10 Papers/`, `20 Concepts/`, `30 Maps/`
