# 11주차 — Text Embedding과 Vector Database

## 학습 목표

문장과 문서를 의미 벡터로 변환하고 Chroma에 저장해 의미적으로 가까운 문서를 검색한다.

## 핵심 용어

- **Text Embedding**: 텍스트 의미를 비교 가능한 밀집 벡터로 변환한 표현.
- **Embedding Model**: 텍스트를 같은 벡터 공간에 배치하도록 학습된 모델.
- **Vector Database**: 벡터·원문·metadata를 저장하고 근접 검색하는 데이터베이스.
- **Chroma**: 강의에서 사용한 로컬 vector database.
- **Similarity Search**: 질의 embedding과 가까운 문서 embedding을 찾는 검색.
- **Cosine Similarity**: 벡터 방향의 유사성. [[Cosine Similarity]]
- **L2 Distance**: 벡터 사이의 직선 거리. 점수 해석 방향은 라이브러리마다 확인해야 한다.
- **Top-k**: 관련도 순으로 반환할 결과 개수.
- **Metadata**: 문서에 붙이는 category·source 같은 구조화 속성.
- **Metadata Filter**: 특정 속성에 맞는 문서만 검색 후보로 제한하는 기능.
- **Persistence**: 저장소를 디스크에 보존하고 다시 불러오는 기능.
- **PCA**: 고차원 embedding을 시각화를 위해 저차원으로 축소하는 방법. [[Principal Component Analysis]]

## 키워드 검색과 의미 검색

| 검색 | 강점 | 약점 |
|---|---|---|
| 키워드 | 정확한 문자열·코드 | 동의어와 표현 변형 |
| 의미 검색 | 동의어·문장 의미 | 식별자와 정확 일치 |
