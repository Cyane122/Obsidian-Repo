# 8주차 — GPT와 자기회귀 생성

## 학습 목표

Transformer Encoder와 GPT Decoder의 차이를 causal masking 관점에서 이해하고 사전학습 모델로 텍스트를 생성한다.

## 핵심 용어

- **GPT**: 다음 토큰 예측으로 사전학습하는 Decoder-only Transformer. [[GPT]]
- **Decoder-only Transformer**: 왼쪽 문맥만 이용해 출력을 생성하는 Transformer 구성.
- **Causal Mask**: 현재 위치가 미래 토큰을 보지 못하게 하는 상삼각 mask.
- **Next-Token Prediction**: 이전 토큰들이 주어졌을 때 다음 토큰의 확률 분포를 예측하는 학습 목표.
- **Autoregressive Generation**: 생성한 토큰을 다시 입력에 붙여 다음 토큰을 반복 생성하는 방식.
- **Pretraining**: 대규모 일반 말뭉치에서 범용 패턴을 먼저 학습하는 단계.
- **Fine-tuning**: 사전학습 모델을 특정 과업·데이터에 추가 학습하는 단계.
- **Prompt**: 모델에 제공하는 과업 지시와 맥락.
- **Zero-shot**: 과업 예시 없이 지시만으로 수행하는 설정. [[Zero-Shot Transfer]]
- **Few-shot**: 소수의 입력·출력 예시를 프롬프트에 제공하는 설정. [[Few-Shot Learning]]
- **Temperature**: 생성 분포의 다양성을 조절하는 값.

## 핵심 관계

`GPT = Transformer Decoder + Causal Mask + Next-Token Prediction`

## 선택 관점

- 작은 데이터와 빠른 baseline: TF-IDF + 전통적 분류기
- 순서가 중요한 지도학습: LSTM
- 사전학습 표현과 분류: BERT 계열
- 열린 텍스트 생성: GPT 계열
