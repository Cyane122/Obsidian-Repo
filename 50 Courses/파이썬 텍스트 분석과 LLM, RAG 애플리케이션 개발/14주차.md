# 14주차 — LangGraph 기본

## 학습 목표

State·Node·Edge로 실행 흐름을 구성하고 조건 분기와 반복을 명시적으로 제어한다.

## 핵심 용어

- **LangGraph**: 상태 기반 그래프로 LLM·도구 워크플로를 구성하는 프레임워크.
- **State**: 모든 노드가 읽고 갱신하는 공유 데이터 구조.
- **TypedDict**: State의 필드와 타입을 선언하는 Python 타입 표현.
- **Node**: State를 받아 변경할 필드 값을 반환하는 실행 함수.
- **Edge**: 노드 사이의 실행 순서를 나타내는 연결.
- **START / END**: 그래프 실행의 진입점과 종료점.
- **StateGraph**: State schema를 기준으로 노드와 edge를 조립하는 builder.
- **Compile**: 그래프 정의를 실행 가능한 객체로 변환하는 단계.
- **Invoke**: 초기 State를 전달해 compiled graph를 실행하는 호출.
- **Reducer**: 여러 상태 갱신을 병합하는 규칙.
- **Overwrite**: reducer가 없을 때 같은 필드의 이전 값을 새 값으로 교체하는 동작.
- **`operator.add`**: 리스트 등 누적 가능한 필드에 사용하는 reducer 예시.
- **Conditional Edge**: router의 판단 결과에 따라 다른 노드로 이동하는 분기.
- **Router**: State를 읽고 다음 경로 이름을 반환하는 함수.
- **Loop**: 조건이 만족될 때 이전 노드로 되돌아가는 반복 경로.
- **Recursion Limit**: 무한 반복을 막기 위한 최대 실행 횟수 안전장치.
- **LLM Node**: 노드 내부에서 모델을 호출해 State를 갱신하는 구성.

## 기본 구조

```text
State 정의
→ Node 등록
→ Edge 또는 Conditional Edge 연결
→ Compile
→ Invoke
```

## 핵심 주의

- 반복 경로에는 반드시 종료 조건이 있어야 한다.
- 여러 노드가 같은 State 필드를 갱신할 때 overwrite인지 누적인지 명시한다.
- 노드가 전체 State를 다시 만들기보다 변경할 필드만 반환하도록 구성한다.
