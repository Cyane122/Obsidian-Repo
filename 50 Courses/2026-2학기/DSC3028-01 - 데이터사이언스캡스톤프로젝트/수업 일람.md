## 캡스톤 프로젝트
### 발표 평가
- 자신의 팀을 제외한 모든 팀의 매 발표(Proposal, 분석 레포트, 최종 발표 등)에 대한 평가를 Google Form으로 제출해야 함
- 각각의 팀에게 그 점수가 피드백으로 제공될 예정
- 발표 평가 제출은 필수이며 출석/참여 점수에 반영
- 미제출 시 부분적으로라도 결석될 수 있음
### 팀 구성
- 모든 팀은 최대 4인으로 구성되어야 함
- 각각의 팀은
	- 팀 리더를 선출해야 함
		- 그룹의 회의 등을 주선
		- 과제의 종료 기한과 제출이 제대로 진행되었는지 검수
	- 그룹명을 정해야 함
- 팀 구성에 어려움이 있다면 교수님에게 즉각 알릴 것
### 프로젝트 Proposal 발표
- 팀의 구성 정보(팀명, 팀원, 리더) 소개
- 프로젝트 Proposal
	- 데이터 설명
	- 데이터 출처
	- 데이터셋 크기
	- 변수 개수
	- 핵심 질문(무엇을 하고 싶은지)
### 데이터 분석 레포트 & 발표
- 데이터 분석과 정제
- 데이터 전처리 테크닉
	- 데이터 시각화, descriptive statistics 등을 적용할 것
	- 데이터의 범위와 질에 대해 학습할 것
	- missing variable이나 outlier를 확인할 것
- 데이터 분석 레포트
	- 5~7페이지 권장
	- 전처리 단계를 설명할 것
	- 변수 변환, 이상치 분석, 데이터 property 평가, missing value에 대한 결정
### 프로젝트 현황 점검
- 각각의 팀은 프로젝트의 진행 상황을 설명하는 5~10분 가량의 발표를 진행해야 함
	- 프로젝트 기여도
	- 작업 도중 당면한 문제점
	- 추후 계획
- 학우들과 토론/피드백
