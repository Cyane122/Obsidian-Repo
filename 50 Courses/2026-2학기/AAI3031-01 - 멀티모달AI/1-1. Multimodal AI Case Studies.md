> [!abstract] 핵심
> 영상 감시는 행동에 문맥을 더하고, Dehazing은 열화 유형에 맞는 복원 model을 선택하며, 통화 분석은 현재 prediction을 이력과 지식으로 보완한다.

## 1. Abnormal Situation Monitoring: 행동과 문맥의 결합

### 행동과 Context

특허는 같은 달리기라도 조깅 코스에서는 일상적인 운동으로, 혼잡한 도로변에서는 수상한 행동으로 해석하는 예시를 든다. 행동과 함께 **장소·시간 등 주변 문맥**을 분석해 정상·비정상을 판단한다.

```text
Video → Key Frames → Object Analysis
                         ├─ Object Sequence → Behavior
                         └─ Key-frame Sequence → Context
Behavior + Context → Abnormal Situation Prediction → Warning
```

### Two Streams: 객체 중심과 장면 중심

원문은 같은 영상에서 두 종류의 sequence를 만든다.

| 처리 흐름 | Input 구성 | 판단 대상 |
| --- | --- | --- |
| Object-centered stream | 각 frame에서 찾은 동일 객체를 시간 순서로 묶은 object sequence | 걷기, 달리기, 자전거 타기, 운전 등의 behavior |
| Context-centered stream | 동일 객체가 등장하는 key frame들을 시간 순서로 묶은 frame sequence | 행동이 발생하는 장소·시간 등 surrounding context |

원문은 CNN으로 연속 frame의 optical-flow feature를 추출하고, 시간 순서의 feature를 복수 LSTM에 전달하는 구성을 설명한다. 행동과 문맥 후보를 probability로 표현한 뒤, 행동과 문맥의 matching 정도로 abnormal situation을 판단한다.

Optical flow는 연속 frame 사이의 motion을 표현하고, LSTM은 sequence의 시간적 의존성을 처리한다.

### Camera Agent와 이웃 Camera의 협력

Camera agent는 camera, communication module, memory, processor를 갖추고 영상 분석과 정보 교환을 수행한다.

각 agent는 자체적으로 행동·문맥·비정상 여부를 분석하고, 인접 agent와 다음 정보를 공유한다.

- Context probability와 abnormal situation prediction probability
- Warning 출력 여부
- 대응하는 사건을 식별하기 위한 timestamp, agent identifier, location 정보

인접 agent는 감시 영역의 적어도 일부를 함께 촬영하는 관계로 설정할 수 있다. 원문은 원본 영상 전체보다 용량이 작은 상위 분석 결과를 공유하는 구조를 설명한다.

문맥 결합에는 가장 큰 probability를 갖는 context를 선택하는 방식과, camera별 probability에 weight를 곱해 합산한 뒤 최대값을 선택하는 방식이 제시된다. 갱신한 context로 prediction을 재산출하고, 경고의 일치 여부도 비교한다.

강의 개념에 연결하면, camera 사이에서 동일 대상·사건을 대응시키는 과정은 Alignment, probability를 공유해 결론을 갱신하는 과정은 decision-level Fusion으로 볼 수 있다.

### Multimodal 관점에서의 위치

Input은 video이며, 두 stream은 객체·문맥의 서로 다른 representation을, 여러 camera는 서로 다른 시점을 제공한다.

## 2. Haze-Aware Dehazing: 열화 유형에 맞는 Model 선택

### Single-image restoration의 문제

US 12,217,398 B1, *Apparatus and Method for Single Image Dehazing Considering Haze Type Classification*은 입력 영상의 haze type을 분류한 다음, 그 유형에 맞는 specialized dehazer를 선택한다.

```text
Hazy Image → Haze-type Classification → Specialized Dehazer Selection
           → Dehazing Inference → Dehazed Image → Downstream Task
```

분류 대상에는 cloud, fog, smoke, rain 등 여러 열화 조건이 포함된다.

**상태를 먼저 추정하고 적합한 처리 경로를 선택하는 conditional processing**으로, haze classifier가 사용할 dehazer를 결정한다.

### SSC와 HCC

| 분류 방식 | 원문이 설명하는 동작 | 해석 |
| --- | --- | --- |
| Single Selective Classifier, SSC | 사용자가 선택한 특정 classifier로 haze type을 추론 | 한 classifier의 결과로 경로 선택 |
| Hybrid Conditional Classifier, HCC | 여러 사전학습·사전정의 classifier의 predicted class와 probability를 condition block에서 처리 | 복수 model의 결과를 조건에 따라 종합 |

HCC는 model의 class prediction, confidence 및 accuracy 등을 활용해 final predicted class를 결정한다.

### Training과 Inference의 구분

원문은 ground-truth image를 outdoor, street, farmland, satellite image set 등으로 구분하고, synthetic haze와 intensity를 적용해 학습용 hazy dataset을 구성하는 절차를 포함한다. 이 dataset으로 haze classifier들과 specialized dehazer들을 학습한다.

Haze type별 local server에서 specialized dehazer를 학습하고, weight를 global federated server에 모은다.

- **Training:** 열화 조건별 model을 준비하고 학습한다.
- **Inference:** 현재 입력의 haze type을 판단하고 대응 model을 선택해 복원한다.

Image를 입력으로 model routing과 분산 학습을 결합한 구조다.

복원 결과는 object detection, segmentation, context analysis 등의 후속 task에 사용할 수 있다.

### Follow-up Patent: Vehicular Images

US 12,277,682 B1, *Method for Image Dehazing of Vehicular Images*는 선행 출원 18/658,673의 **continuation**이다.

| 비교 항목 | US 12,217,398 B1 | US 12,277,682 B1 |
| --- | --- | --- |
| 대상 | Haze-type-aware single-image dehazing | Vehicular image dehazing |
| 독립 청구항의 input | Haze condition과 haze-type class를 가진 image | Vehicle에서 얻은 image이며 autonomous vehicle의 camera에서 획득함을 명시 |
| 공통 처리 | Classifier 선택 → haze type 판단 → specialized dehazer 선택 → 복원 | 같은 핵심 처리 흐름을 포함 |
| 자료 관계 | 후속 문서가 지목하는 선행 출원 | 해당 출원의 continuation |

선행 특허는 autonomous vehicle camera 또는 surveillance camera를 포함한다. 후속 특허는 autonomous vehicle의 camera에서 얻은 input을 **독립 청구항**에 명시한다.

## 3. Fake Call Analysis: LISTEN과 Speech Emotion Reasoning

### LISTEN Project

강의 슬라이드는 speech와 environmental sounds 분석을 통한 situation awareness를 소개한다. LISTEN project의 주요 module과 관련 연구·특허를 소개한 뒤, reasoning을 이용하는 Speech Emotion Recognition, SER 구조를 설명한다.

LISTEN의 주요 module은 다음과 같다.

| Module | 역할 |
| --- | --- |
| Gender Recognition | 음성에서 화자의 gender 관련 속성을 추정 |
| Age Prediction | 음성에서 age 또는 age group을 추정 |
| Speech Emotion Recognition | 발화 구간의 emotion을 분류 |
| Fusion and Reasoning | 여러 분석 결과·근거를 결합해 판단을 보완 |

### Speech → Spectrogram → 3D CNN

SER 구조는 speech signal을 Fourier Transform으로 spectrogram으로 변환하고, 고정 time slot으로 나눈 spectrogram들을 세 번째 축으로 쌓는다. 3D CNN은 이 sequence에서 feature를 추출하고 Softmax classifier는 일곱 emotion의 probability를 출력한다.

```text
Speech Signal → Spectrogram Sequence → 3D CNN → Emotion Probabilities
             → Confidence Check → Evidence Validation / Reasoning
             → Final Emotion + Speaker's Emotional History
```

Emotion class는 Happy, Sad, Fear, Angry, Boredom, Disgust, Neutral이다. Spectrogram의 시간·주파수 배열에서 short-term feature를 추출하고, 쌓인 sequence에서 long-term feature를 추출한다.

Spectrogram은 audio의 시간·주파수 representation이다.

### Confidence와 Reasoning

슬라이드는 maximum probability를 confidence 기준으로 사용한다. 두 threshold $T_1$, $T_2$로 High, Medium, Low confidence를 구분하고, low-confidence 결과를 버리는 흐름을 제시한다. High-confidence 결과도 다른 emotion과의 충돌 여부를 확인한다.

현재 prediction을 보완하는 근거는 크게 두 종류다.

1. **Speaker's History:** 이전 $N$개 speech segment에서 어떤 emotion이 얼마나 자주 나타났는지 확인한다.
2. **Emotion Co-existence Knowledge:** emotion 조합이 함께 나타날 가능성에 관한 knowledge base를 참조한다.

History의 emotion별 score는 다음과 같다.

$$H(E)=\frac{\text{이전 }N\text{개 segment에서 emotion }E\text{의 출현 횟수}}{N}$$

예를 들어 이전 7개 중 Sad가 4회, Neutral이 3회면 history score는 각각 $4/7$, $3/7$이다.

Co-existence table은 psychological studies와 experts' opinions에 근거해 두 emotion 또는 세 emotion 조합에 score를 부여한다. 슬라이드의 예시에서 conflicting 조합은 낮고 co-existent 조합은 높은 score를 갖는다.

### Reliability-Weighted Fusion

현재 구간의 emotion 후보 $E$에 대해 세 근거의 score를 결합한다.

$$F(E)=\sum_{i=1}^{3}r_iS_i(E)$$

| 근거 | $S_i(E)$의 의미 | 예시 weight |
| --- | --- | --- |
| Original Prediction | 현재 classifier가 출력한 emotion score | $r_1=0.15$ |
| Speaker's History | 이전 segment의 emotion 출현을 이용한 score | $r_2=0.50$ |
| Emotion Co-existence | Knowledge base에서 얻은 조합의 score | $r_3=0.35$ |

각 score에 reliability weight를 곱해 합산하고, fused score가 가장 높은 emotion을 선택한다. 위 weight는 슬라이드의 예시 설정이다.

### Fusion 계산 예시

**Happy와 Neutral의 score 결합**

- Happy의 $(S_1,S_2,S_3)=(0.50,0.60,0.99)$ → $F(Happy)=0.15(0.50)+0.50(0.60)+0.35(0.99)=0.7215$
- Neutral의 $(S_1,S_2,S_3)=(0.58,0,0.79)$ → $F(Neutral)=0.3635$
- 현재 classifier score만 보면 Neutral이 높지만, 세 근거를 결합하면 Happy를 선택한다.

**Sad와 Happy: 이전 5개 segment를 이용한 판단**

- 이전 5개 segment는 Happy 4회, Neutral 1회이므로 $H(Happy)=0.8$, $H(Neutral)=0.2$다.
- 현재 후보는 Sad 0.34와 Happy 0.31이다. Sad의 history score는 0이고, Happy의 history score는 0.8이다.
- Knowledge base에서 Happy–Neutral–Sad 조합은 0.2, Happy–Neutral–Happy 조합은 0.7이다.
- $F(Sad)=0.15(0.34)+0.50(0)+0.35(0.20)=0.121$
- $F(Happy)=0.15(0.31)+0.50(0.80)+0.35(0.70)=0.6915$ → Happy 선택

Sad–Happy 예시의 Happy score는 원문에 **0.691**로 표기되어 있으나, 제시된 값의 계산 결과는 **0.6915**다.

두 예시는 각각 Happy–Neutral과 Sad–Happy를 비교하는 별도 scenario다. Sad–Happy의 fusion에는 Sad의 history score 0과 Happy의 0.8을 사용한다.

### Emotional History의 유지와 활용

슬라이드는 high-confidence·non-conflicting output을 이용해 화자의 emotional history를 유지하고, 신뢰도 높은 spectrogram과 annotation을 축적해 iterative fine-tuning에 쓰는 구조를 제시한다. History는 이후 segment의 reasoning과 통화 전체 emotional state의 요약에 활용한다.

세 sources는 **현재 audio prediction, 그 화자의 이전 audio 분석 결과, emotion knowledge**다. Audio에서 얻은 현재·과거의 분석 결과를 knowledge base와 결합한다.
