> [!abstract] 핵심
> Intelligent Baby Monitoring은 camera video에서 작은 움직임을 검출하고, 움직임의 크기와 분포를 바탕으로 아기의 행동을 관찰하는 사례다. 강의는 Frame Difference, Optical Flow, Background Subtraction과 세 결과의 intersection을 사용하는 Hybrid Method를 비교한다. 이후 움직임을 ellipse로 표현하고 Movement Intensity·Diversity를 Control Chart에 연결하는 행동 분석 시스템을 제안한다.

## 문제 설정과 관찰 대상

아기를 계속 직접 관찰하기 어려운 환경에서 camera가 움직임을 포착하고 보호자에게 상태를 전달하는 것이 목표다. 가정에서 다른 일을 하는 상황과 nursery에서의 관찰 필요성이 연구 동기다.

착용형 sensor는 신체에 부착하고 유지해야 한다. Camera는 신체에 직접 부착하지 않고 영상을 얻을 수 있지만, 호흡처럼 변화량이 작은 움직임을 image processing으로 구별해야 한다.

먼저 video에서 **Motion Detection**을 수행하고, 검출한 움직임을 행동 분석의 입력으로 사용한다.

| 단계 | 처리 대상 | 얻는 정보 |
| --- | --- | --- |
| Motion Detection | 연속 frame과 background | 변화가 일어난 pixel·region |
| Motion Representation | 검출된 motion region | 움직임을 표시하는 ellipse의 크기와 개수 |
| Behavior Assessment | 시간에 따른 motion feature | Control Limit에 대한 관측값의 위치 |
| Reporting | 판단 결과 | 보호자에게 전달할 알림 |

강의의 네 방법은 pixel difference, flow, foreground mask와 threshold를 조합하는 전통적 image processing pipeline이다.

## Motion Detection의 공통 흐름

네 방법은 같은 video에서 연속 frame을 처리한다. Frame Difference는 시간에 따른 밝기 변화를, Optical Flow는 영상 속 움직임의 방향과 크기를, Background Subtraction은 background와의 차이를 이용한다.

각 결과를 binary mask로 바꾸면 pixel을 motion 후보와 나머지 영역으로 나눌 수 있다. 이후 noise를 제거하고 motion region을 선택하거나 여러 mask를 결합한다.

이하 수식은 강의의 처리 흐름을 설명하기 위한 표기다.

$$F_t(x,y):\text{time }t\text{의 frame},\qquad M_t(x,y)\in\{0,1\}$$

$M_t=1$은 해당 pixel이 motion 후보임을 나타낸다.

### Frame Difference

**Frame Difference**는 인접한 두 frame의 pixel 차이로 움직임을 추정한다. 같은 위치의 값이 충분히 달라졌다면 변화가 발생한 pixel로 표시한다.

설명용으로 absolute difference와 binary thresholding을 다음과 같이 나타낼 수 있다.

$$D_t(x,y)=|F_{t+1}(x,y)-F_t(x,y)|$$
$$M_t^{FD}(x,y)=\mathbf{1}[D_t(x,y)>\tau_{FD}]$$

처리 순서는 **Consecutive Frames → Absolute Difference → Binary Image → Morphological Operations → Motion Area Selection**이다. Morphological Operations는 binary result의 작은 noise를 정리하고 region을 다루기 위한 단계다.

두 frame의 차이를 직접 이용하므로 구조가 단순하다. 작은 움직임은 threshold 아래에 묻힐 수 있고, 조명 변화와 camera 흔들림은 pixel difference에 함께 반영된다.

### Optical Flow

**Optical Flow**는 연속 frame에서 image pattern이 어느 방향으로 얼마나 이동했는지 추정하는 방법이다. Frame Difference가 pixel 변화 여부를 중심으로 본다면, Optical Flow는 frame 사이의 displacement를 표현한다.

강의의 흐름은 **Consecutive Frames → RGB to HSI → Optical Flow → Binary Motion Estimation → Maximum Flow Region Selection**이다.

Flow vector를 설명용으로 다음과 같이 나타낼 수 있다.

$$\mathbf{v}_t(x,y)=(u_t(x,y),v_t(x,y))$$
$$\|\mathbf{v}_t\|=\sqrt{u_t^2+v_t^2}$$

$u_t,v_t$는 영상 평면에서의 이동 성분이다. Flow의 magnitude를 이용하면 움직임의 크기를 region 선택에 반영할 수 있다. 강의는 flow를 binary image로 변환하고 큰 flow region을 둘러싸는 과정을 보여준다.

### Background Subtraction

**Background Subtraction**은 static camera의 current frame과 background model의 차이를 바탕으로 foreground mask를 생성한다.

설명용으로 background model을 $B_t$라고 하면 다음과 같이 표현할 수 있다.

$$M_t^{BS}(x,y)=\mathbf{1}[|F_t(x,y)-B_t(x,y)|>\tau_{BS}]$$

처리 순서는 **Background Model·Current Frame → Subtraction → Threshold → Foreground Mask → Region Selection**이다.

Frame Difference는 인접 frame을, Background Subtraction은 유지하고 있는 background model과 current frame을 비교한다. Background model의 생성·갱신 방식과 shadow 등 환경 변화가 foreground mask에 영향을 준다.

### Hybrid Method

**Hybrid Method**는 세 방법에서 얻은 binary motion estimate를 결합한다. **Intersection**으로 final motion을 얻고, motion area를 계산하거나 expert data와 비교해 ellipse를 그린다.

Intersection의 의미를 설명용으로 표현하면 다음과 같다.

$$M_t^{H}=M_t^{FD}\cap M_t^{OF}\cap M_t^{BS}$$

같은 pixel을 세 방법이 공통으로 motion이라고 판단한 영역을 남긴다. 한 방법만 반응한 noise를 줄이는 대신, 한 방법이 놓친 motion도 제외되는 trade-off가 있다.

Area에 따라 confidence를 100%·95%·90%·80%로 표시하며, area 단위와 20–30 범위·일부 경계의 처리는 불명확하다.

## 네 방법의 비교

| 방법 | 비교·추정 기준 | 주요 output | 특징 |
| --- | --- | --- | --- |
| Frame Difference | 인접 frame의 pixel difference | 변화한 pixel의 binary mask | 작은 변화와 noise의 구분이 threshold에 영향받음 |
| Optical Flow | 연속 frame의 pattern displacement | flow 및 binary motion region | 이동 방향과 크기 추정 |
| Background Subtraction | background model과 current frame | foreground mask | background 유지와 static camera 조건이 중요함 |
| Hybrid | 세 binary estimate의 intersection | 공통 motion region | noise 억제와 motion 누락 사이의 trade-off가 있음 |

Hybrid는 세 pipeline을 함께 처리하므로 계산 비용이 상대적으로 크다.

## Baby Behavior Analysis 시스템

Baby Behavior Analysis 시스템은 motion detection을 **interval 단위 행동 분석과 알림**으로 확장한다.

전체 처리 흐름은 다음과 같다.

1. Camera에서 input video를 얻는다.
2. Video를 여러 interval로 나눈다.
3. Baby를 background에서 분리하고 interval 내 motion area를 계산한다.
4. Expert size information과 motion region을 비교해 ellipse를 그린다.
5. Ellipse에서 Intensity와 Diversity를 얻어 Control Chart를 구성한다.
6. Control Limit을 벗어나는 관측을 판단하고 보호자에게 알린다.

### Ellipse와 Motion Feature

Motion region을 ellipse로 표현하고 그 크기와 개수를 각각 feature로 사용한다.

| Feature | 자료의 표현 | 의미 |
| --- | --- | --- |
| Movement Intensity $I$ | ellipse의 size | 얼마나 큰 motion region이 관찰되는지 나타냄 |
| Movement Diversity $D$ | ellipse의 number | 서로 나뉘어 표현되는 motion region의 수를 나타냄 |

### Camera Height와 Size Calibration

같은 신체 부위도 camera와의 거리, 시점, 영상 내 크기에 따라 pixel size가 달라진다. 크기 보정에는 camera와 baby의 거리 정보, Frame-to-Baby Ratio, expert knowledge의 body-part size를 함께 사용한다.

촬영 조건에 맞게 크기를 보정하고, **각 ellipse의 크기를 body-part size 이내로 제한**한다. Size prior로 3·6·12·18·24개월의 baby size chart를 사용한다.

### Control Chart와 LCL·UCL

**Control Chart**는 interval 안에서 얻은 Intensity와 Diversity를 Control Limit과 함께 표현한다. 각 point는 interval 내 consecutive frame 사이의 motion difference를 바탕으로 배치된다.

- **LCL — Lower Control Limit**: 하한.
- **UCL — Upper Control Limit**: 상한.
- 하한 아래의 motion은 움직임이 지나치게 적은 상태로 표시한다.
- 상한 위의 motion은 움직임이 지나치게 큰 상태로 표시한다.

움직임이 LCL 아래로 떨어지거나 UCL 위로 올라가면 보호자에게 알린다.

Alert 조건을 feature별 한계로 풀어 쓴 설명용 식은 다음과 같다.

$$\text{Alert}_t=(I_t<LCL_I)\lor(I_t>UCL_I)
\lor(D_t<LCL_D)\lor(D_t>UCL_D)$$

Intensity 또는 Diversity 가운데 하나라도 허용 범위를 벗어나면 abnormal behavior 경로로 진행한다. 그렇지 않으면 normal behavior 경로를 거쳐 다음 interval을 처리한다.

Interval별 chart를 나열하거나 Time·Intensity·Diversity의 관계를 입체적으로 표현해 시간에 따른 motion pattern을 살펴볼 수 있다.

### Motion Estimation과 Behavior Estimation의 연결

Motion Estimation은 두 연속 frame에서 absolute difference를 계산하고 noise를 제거하며, Optical Flow와 Background Subtraction의 binary motion estimate를 함께 integration한다. 이 결과가 final motion computation으로 이어진다.

Motion computation 다음에는 interval의 모든 frame에 ellipse를 그리고, Intensity·Diversity로 Control Chart를 만든다. 마지막 interval이 아니면 다음 interval을 선택해 같은 과정을 반복한다.

## Multimodal AI와의 관계

이 사례는 하나의 camera video에 세 알고리즘을 적용하는 **single-modality, multiple-method fusion**이다. Expert size information은 영상 해석을 돕는 prior knowledge로 사용한다.

## 결론과 향후 방향

Motion Detection → Size Calibration → Ellipse Feature → Control Chart → Alert로 이어지는 pipeline이 핵심이다. 향후 방향은 video 수·scenario·challenge 측면의 dataset 확장과 더 상세한 behavior analysis다.
