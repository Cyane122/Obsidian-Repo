# 1주차 - Introduction to Multimodal AI

> [!abstract] 핵심
> 현실의 사건은 여러 신호를 만든다. Multimodal AI는 서로 다른 modality를 **Representation → Alignment → Fusion**의 흐름으로 연결해, 단일 신호만으로는 하기 어려운 추론과 판단을 수행한다.

## The Real-World Problem

- 한 사건에서 여러 signal이 나온다.
  - 예: 도로를 지나는 자동차 → camera feed, 차량 소리, LiDAR, navigation map, sensor signal
- 단일 정보는 상황을 신뢰성 있게 이해하기에 충분하지 않을 수 있다.
- 판단할 때 생각할 점
  - 어떤 signal을 신뢰할 것인가?
  - 그 signal은 언제 실패할 수 있는가?
  - 다른 signal은 이를 보완하거나 반박하는가?

## Why Multimodal AI?

- 전통적인 AI는 보통 하나의 정보 유형에 특화된다.
  - Computer Vision, NLP, Speech AI, Video Understanding, Sensor AI
- 그러나 현실 세계는 하나의 정보원만으로 주어지는 경우가 드물다.
- 핵심 생각
  - 현실은 multimodal이다.
  - 지능 시스템은 heterogeneous information을 통합하는 mechanism이 필요하다.

## What is Multimodal AI?

**Multimodal AI**는 여러 modality에서 온 정보를 처리하고, 표현하고, 연결하고, 추론하는 AI system이다.

- **Perceive**: 각 정보원을 인식한다.
- **Align**: 서로 다른 정보원에서 대응하는 부분을 찾는다.
- **Reason**: 여러 정보원을 근거로 판단한다.

> [!note] 구분
> Multimodal AI는 여러 AI model을 단순히 붙여 놓는 방식이 아니다. 서로 다른 형식의 정보를 의미 있게 상호작용할 수 있는 표현으로 만드는 일이 중심이다.

## Understanding Modality

**Modality**는 정보를 관찰하거나 표현하는 서로 다른 channel 또는 form이다. 같은 현실을 서로 다른 관점에서 보여 준다.

| Modality | Typical data | 교수님 예시·특성 |
| --- | --- | --- |
| Vision | image, pixel | photograph, spatial structure, high-dimensional, local relationship |
| Text | word, document | question, sequential/symbolic, discrete token, semantic meaning |
| Audio | waveform, spectrogram | speech, temporal signal, frequency, prosody |
| Video | frame + time | human activity, motion, long-range temporal dependency |
| Sensor | measurement, signal | temperature, IMU, sampling rate, noise, missing value |
| 3D / Spatial | point cloud, depth | LiDAR |
| Structured Data | table, event | patient record |

## Why Are Modalities Different?

- Vision: 공간 구조와 시각적 의미를 가진다.
- Text: 순서가 있는 이산 token으로 의미를 표현한다.
- Audio: 시간·주파수·억양 정보가 중요하다.
- Video: 공간 구조와 시간 변화, motion을 함께 다룬다.
- Sensor: 연속적인 수치 신호이며 물리 제약, noise, 결측이 있다.

따라서 image의 pixel, text의 token, audio의 waveform은 바로 비교할 수 없다. Multimodal system에는 modality별 **Representation Learning**, modality 사이의 **Alignment**, 정보의 **Fusion**이 필요하다.

## The Multimodal Pipeline

```text
Observe → Represent → Align → Fuse → Reason → Act
```

- **Observe**: camera, microphone, sensor, document 등에서 입력을 받는다.
- **Represent**: raw input을 embedding으로 바꾼다.
- **Align**: 같은 대상·사건·시점을 가리키는 정보를 연결한다.
- **Fuse**: 필요한 정보를 하나의 representation 또는 decision으로 결합한다.
- **Reason / Act**: 답을 만들고, 예측·경보·제어로 이어 간다.

### 예시: Image + Question

- Image: 자전거 옆에 앉은 dog
- Question: “What is beside the bicycle?”
- 필요한 과정
  1. image → visual representation
  2. question → language representation
  3. bicycle과 image 속 객체를 alignment
  4. multimodal reasoning → **Dog**

## Three Core Concepts

### 1. Representation

- 각 modality가 상호작용하기 전에 shared computational form으로 바뀌어야 한다.
- raw input은 learned representation, 즉 embedding으로 encoding된다.
- embedding
  - raw data를 continuous geometric space의 dense vector로 옮긴 표현
  - 의미가 비슷한 입력은 가깝게, 다른 입력은 멀게 놓이도록 학습한다.
- 예시
  - “cat” text, cat image, cat sound는 modality가 달라도 같은 개념을 나타내면 가까운 embedding이 될 수 있다.
- [[Word Embedding]]은 텍스트를 vector로 표현하는 관련 사례다.

### 2. Alignment

- **Multimodal Alignment**: modality 사이의 correspondence를 학습하는 과정
- 질문: “한 modality의 무엇이 다른 modality의 무엇을 가리키는가?”
- alignment 수준
  - semantic: image의 객체 ↔ text의 단어
  - temporal: video frame ↔ audio 구간 또는 event
- 어려운 이유
  - continuous/discrete 표현의 차이
  - frame rate, token 길이, sampling rate의 차이
  - 공간 구조와 추상화 수준의 차이
  - noise와 missing information
- [[Learning Transferable Visual Models From Natural Language Supervision|CLIP]]은 image-text 쌍을 [[Contrastive Learning]]으로 정렬한 사례다.

### 3. Fusion

- **Multimodal Fusion**: 여러 modality의 정보를 unified representation 또는 decision space로 결합하는 과정
- 질문: “정렬된 정보를 추론이나 예측에 어떻게 합칠 것인가?”

| 방식 | 결합 시점 | 특징 |
| --- | --- | --- |
| Early Fusion | raw input 또는 low-level feature 단계 | 단순하지만 modality별 구조를 충분히 처리하기 어렵다 |
| Intermediate Fusion | modality별 encoding 뒤 interaction layer | modality별 구조를 보존하며 상호작용한다. 현대 multimodal model에서 많이 사용한다 |
| Late Fusion | modality별 독립 prediction 뒤 | missing modality에 비교적 견고하지만 깊은 상호작용은 제한된다 |

- Fusion이 특히 유용한 경우
  - **Complementary information**: 서로 다른 측면을 보완
  - **Redundant information**: 여러 신호로 같은 판단을 확인
  - **Contextual information**: 한 modality가 다른 modality의 모호성을 줄임

## Application Landscape와 주의할 점

수업에서 다룰 사례

- Image Enhancement & Restoration
- Intelligent Baby Monitoring
- Fire & Smoke Detection
- Agent-Based Fire Monitoring
- Human Action Recognition
- Aggressive Behavior Monitoring
- Industrial Anomaly Detection
- Sensor-Based Human Action Recognition

시스템을 볼 때 함께 확인할 한계

- noise와 missing modality
- 잘못된 Alignment
- 여러 encoder와 interaction layer의 computational cost
- 학습 data의 bias와 결과의 reliability
