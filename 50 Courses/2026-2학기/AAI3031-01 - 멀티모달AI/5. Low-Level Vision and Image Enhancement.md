> [!abstract] 핵심
> HazeSpace2M framework는 haze type을 분류해 specialized dehazer를 선택하고, TriFuse는 Wavelet·Diffusion·Transformer를 결합해 low-light image를 개선한다. 두 연구는 image quality와 downstream Object Detection 성능을 함께 평가한다.

## Low-Level Vision과 Image Enhancement

Low-Level Vision은 image의 pixel과 local structure에 가까운 수준에서 입력을 복원하거나 개선하는 작업이다. Haze로 낮아진 contrast를 회복하는 Dehazing과 어두운 image를 개선하는 Low-Light Image Enhancement(LLIE)가 이번 강의의 중심이다.

Downstream Recognition은 image에 어떤 object가 있는지, 어디에 있는지, 어떤 상황인지를 해석한다. Object Detection은 class와 bounding box를 예측하므로, 출력 자체가 enhanced image인 LLIE와 구분된다.

| 작업 | 입력의 문제 | 주요 출력 | 평가 관점 |
| --- | --- | --- | --- |
| Dehazing | fog·environmental haze·cloud에 의한 시야 저하 | haze가 감소한 image | reference와의 유사성, 구조·색상 보존 |
| LLIE | 부족한 조명과 낮은 가시성 | 밝기와 detail이 개선된 image | 밝기, noise, 구조, 지각적 품질 |
| Object Detection | object의 위치와 class를 알아야 함 | bounding box와 class | detection 성능 |

Brightness 증가는 어두운 object와 noise를 함께 드러내고, 강한 sharpening은 경계 주변에 artifact를 만들 수 있다. 도로 scene의 enhancement에서는 밝기·구조 보존과 detection 성능을 함께 평가한다.

두 연구의 입력 modality는 RGB image 하나다. TriFuse는 같은 image의 frequency band에 서로 다른 처리 방식을 적용한다.

## HazeSpace2M Dataset

HazeSpace2M은 다양한 scene과 haze condition에서 Single Image Dehazing을 연구하기 위한 dataset이다. 특정한 haze type이나 synthetic condition에 치우친 기존 설정을 넓히는 것이 자료에서 제시한 동기다.

전체 규모 **약 2.2 million images(2,200,793장)**는 GT와 hazy image의 합계다.

| 구분 | Image 수 | 의미 |
| --- | ---: | --- |
| GT images | 130,193 | paired data의 기준이 되는 image |
| Hazy images | 2,070,600 | 합성 haze image와 Real Haze Testset을 포함한 수 |
| Total | 2,200,793 | GT와 hazy image의 합 |

GT는 Ground Truth를 뜻한다. Paired Dehazing에서는 hazy input에 대응하는 reference가 있으므로, model output을 reference와 비교하는 supervised training과 평가가 가능하다.

### Scene Type과 Haze Type

HazeSpace2M은 **네 가지 scene type**과 **세 가지 haze type**을 다룬다. 세 haze type은 Fog, Environmental Haze(EH), Cloud다.

Scene별 haze condition은 다음과 같다.

| Scene type | 포함하는 haze condition | Haze intensity |
| --- | --- | --- |
| Outdoor | Fog, Environmental Haze | 각 category에 10 levels |
| Street | Fog, Environmental Haze | 각 category에 10 levels |
| Farmland | Fog, Environmental Haze | 각 category에 10 levels |
| Satellite | Cloud | 10 levels |

**Scene diversity**는 배경과 object 구성의 다양성을, **haze diversity**는 열화 양상의 다양성을 의미한다. **Intensity diversity**는 같은 category에서도 열화 강도가 달라지는 설정이다.

### Subset 구성

Fog와 EH를 모두 포함하는 scene은 같은 GT에서 condition별 hazy image를 생성한다.

| Scene | GT images | Hazy images의 구성 |
| --- | ---: | --- |
| Outdoor | 35,936 | Fog 359,360 + EH 359,360 |
| Street | 39,998 | Fog 399,980 + EH 399,980 |
| Farmland | 830 | Fog 8,300 + EH 8,300 |
| Satellite | 53,429 | Cloud 534,290 |
| Real Haze Testset(RHT) | paired GT 수 미제시 | Real hazy images 1,030 |

각 GT에서 10 intensity levels의 hazy image를 생성한다. RHT는 real haze image에서의 generalization 평가에 사용한다.

### GT Quality Assurance

Haze-free reference를 확보하기 위해 GT 수집 과정에서 다음 세 기준으로 image를 선별한다.

- **Resolution**: reference로 쓰기에 적합한 해상도를 고려한다.
- **Haze Presence**: GT에 이미 haze가 포함된 경우를 걸러낸다.
- **Irrelevance**: 목적에 맞지 않는 image를 제외한다.

## Haze-Aware Dehazing Framework

Haze-Aware Dehazing은 입력의 haze type을 판별한 다음, 그 type에 맞는 **Specialized Dehazer(SD)**로 image를 복원한다.

Framework는 Training Block, Classifying Block, Dehazer Picker Block, Dehazing Block으로 구성된다.

| 단계 | 처리 | 역할 |
| --- | --- | --- |
| Training Block | HazeSpace2M으로 haze type classifier 학습 | Fog·EH·Cloud를 구분할 기준 마련 |
| Classifying Block | 입력 hazy image의 type 예측 | 입력의 열화 condition 추정 |
| Dehazer Picker Block | 예측 type에 대응하는 SD 선택 | restoration model 선택 |
| Dehazing Block | 선택된 SD에 원래 hazy image 입력 | dehazed image 생성 |

추론의 흐름은 **Hazy Image → Haze Type Classification → Specialized Dehazer Selection → Dehazed Image**다.

Specialized Dehazer는 Fog, EH, Cloud 각각의 열화 특성에 맞춘 복원 규칙을 학습한다.

### Classification과 Restoration 평가

Haze type classification과 dehazing 결과를 각각 평가한다.

- **Classification evaluation**: haze type을 올바르게 구분하는지 ACC, Precision, Recall 등으로 평가한다.
- **Restoration evaluation**: 복원 image가 reference에 가까운지 PSNR, SSIM, MSE 등으로 평가한다.

Fog·EH·Cloud testset 비교에서 SDNets는 LDNet 및 GDNet보다 높은 평균 PSNR·SSIM과 낮은 평균 MSE를 보였다. 기존 model의 pre-trained weights와 framework 적용 후 결과도 비교한다.

## LoLI-Street Dataset

LoLI-Street은 도로 scene의 **Low-Light Image Enhancement**를 위한 dataset이다. 강의 본문은 **33,000 paired low-light images**와 별도의 **Real-Life Low-Light Testset(RLLT)**을 주요 구성으로 소개한다.

규모 표기는 본문에서 33k paired images, dataset 비교 표에서 image quantity 34,000으로 제시된다.

### Paired Low-Light Data

Paired data에서는 low-light image와 대응 GT를 이용해 복원 방향을 학습한다. 강의의 예시는 GT와 Light, Moderate, Dense condition을 나란히 배치해 밝기 저하 정도에 따른 차이를 보여준다.

| Condition | 강의 예시의 의미 |
| --- | --- |
| GT | 복원의 기준 image |
| Light | 상대적으로 약한 저조도 condition |
| Moderate | 중간 저조도 condition |
| Dense | 더 강한 저조도 condition |

밝기가 낮아지면 object의 texture와 경계가 배경에 묻힌다. LLIE는 brightness와 함께 구조·detail을 복원한다.

### RLLT의 역할

RLLT는 실제 저조도 image의 품질을 BRISQUE와 NIQE로 평가하는 testset이다. Train·validation·test의 average pixel intensity distribution으로 밝기 분포를 비교한다.

## TriFuse의 전체 구조

TriFuse는 LLIE를 위해 **Discrete Wavelet Transform(DWT)**, **Diffusion Denoising**, **Conditional Noise Module(CNM)**, **Edge Sharpening Module(ESM)**을 결합한다.

Low-light image는 DWT를 통해 frequency band로 분해된다. Low-frequency 성분은 denoising 경로로, high-frequency 성분은 ESM 경로로 처리한 뒤 Inverse DWT로 결합한다.

| 구성 | 주된 역할 |
| --- | --- |
| DWT | image를 low-frequency와 high-frequency band로 분해 |
| Diffusion Denoising | noise를 제거하는 역과정을 통해 복원 |
| CNM | low-light condition에 맞는 noise prediction 제공 |
| ESM | high-frequency detail과 경계를 보완 |
| Inverse DWT | 처리한 band를 image로 재구성 |

### Haar Wavelet과 Frequency Decomposition

Haar wavelet을 사용하는 2D-DWT로 image를 분해한다.

$$\{A_1^{\mathrm{low}},V_1^{\mathrm{low}},H_1^{\mathrm{low}},D_1^{\mathrm{low}}\}=\operatorname{2D-DWT}(I_{\mathrm{low}})$$

| 기호 | 의미 |
| --- | --- |
| $I_{\mathrm{low}}$ | 입력 low-light image |
| $A_1^{\mathrm{low}}$ | low-frequency approximation band |
| $V_1^{\mathrm{low}}$ | vertical high-frequency band |
| $H_1^{\mathrm{low}}$ | horizontal high-frequency band |
| $D_1^{\mathrm{low}}$ | diagonal high-frequency band |

Low-frequency band는 image의 완만한 변화와 큰 구조를, high-frequency band는 방향별 급격한 변화와 detail을 담는다.

### Forward Diffusion

Forward Diffusion은 image representation에 단계적으로 Gaussian noise를 더하는 과정이다. 강의의 transition 식은 다음과 같다.

$$q(x_t\mid x_{t-1})=\mathcal N\!\left(x_t;\sqrt{1-\beta_t}\,x_{t-1},\beta_t I\right)$$

$x_t$는 step $t$의 noisy state이고, $\beta_t$는 해당 step의 noise variance schedule 값이다. $I$는 identity matrix다.

### Reverse Diffusion

Reverse Diffusion은 noisy state에서 noise를 제거하면서 복원된 상태로 이동하는 과정이다. 강의는 각 역방향 transition을 learned mean과 variance를 갖는 Gaussian distribution으로 표현한다.

$$p_\theta(\hat x_{t-1}\mid\hat x_t)=\mathcal N\!\left(\hat x_{t-1};\mu_\theta(\hat x_t,t),\sigma_t^2I\right)$$

$\mu_\theta$는 model이 학습하는 mean이고, $\sigma_t^2$는 역과정의 variance다. GT/high-light branch에서 forward diffusion을 학습하고, low-light branch에서 image를 복원한다.

## Conditional Noise Module과 Edge Sharpening Module

### Conditional Noise Module(CNM)

CNM은 입력 condition을 반영해 noise map을 예측하는 module이다. Encoder, Transformer blocks, Decoder를 거쳐 predicted noise를 출력한다.

Transformer blocks에서 image feature 사이의 관계를 처리하고, predicted noise를 reverse diffusion update에 반영한다.

### Edge Sharpening Module(ESM)

ESM은 high-frequency band의 경계와 세부 구조를 보완한다.

ESM은 Depthwise Convolution, 방향별 Residual Block, Cross Attention으로 구성된다. 서로 다른 방향의 detail을 처리하고 관계를 반영한 뒤 보정된 high-frequency band를 출력하는 흐름이다.

Residual 식은 입력 $X$에 convolution 기반 변환 결과를 더해 $Y$를 만드는 형태다. 이때 residual connection은 기존 표현에 학습된 보정량을 더하는 역할을 한다.

ESM의 전체 식도 high-frequency 성분별 처리 결과를 concatenation과 convolution으로 결합한 뒤 입력에 더하는 구조를 나타낸다. 최종적으로 복원된 low-frequency band와 보정된 high-frequency band를 Inverse DWT로 재구성한다.

## 실험 결과의 해석

TriFuse의 실험은 학습 조건별 image quality와 enhancement 후 Object Detection 성능으로 구성된다.

| 비교 | 평가 대상 | Weights 조건 |
| --- | --- | --- |
| 기존 model의 초기 적용 | LoLI-Street validation | 각 model의 pre-trained weights |
| Dataset에 맞춘 학습 후 비교 | LoLI-Street validation | LoLI-Street-trained weights |
| 실제 저조도 평가 | RLLT | pre-trained / trained 조건 구분 |
| Detection utility | enhancement 후 Object Detection | YOLOv10으로 평가 |

### Image Quality Metrics

PSNR, SSIM, MS-SSIM은 표에서 높은 값이 좋은 방향으로 표시된다. LPIPS, MSE, MAE는 낮은 값이 좋은 방향으로 표시된다.

RLLT 표의 BRISQUE와 NIQE는 reference image 없이 image quality를 평가하는 metric이다. 두 metric 모두 자료에서는 낮은 값이 좋은 방향으로 표시된다.

### Pre-trained와 Dataset-trained의 차이

Pre-trained weights로 새 dataset을 평가하는 것은 기존 학습 결과가 새로운 입력에 얼마나 잘 적용되는지를 보는 조건이다. LoLI-Street-trained weights를 쓰는 비교는 해당 dataset에 맞추어 학습한 뒤의 성능을 보는 조건이다.

Visual comparison도 pre-trained와 dataset-trained 조건으로 나누어 수행한다.

LoLI-Street-trained weights를 사용한 Light condition에서 PSNR은 LLFormer 33.40, TriFuse 32.89다. RLLT trained-weights 비교에서 TriFuse는 BRISQUE 10.32, NIQE 10.61을 기록하며, 강의는 이를 SOTA 결과로 소개한다.

### Downstream Object Detection

Enhanced image에 YOLOv10을 적용해 Object Detection 성능을 평가한다.

TriFuse의 mAP(0.5)는 0.753, mAP(0.5–0.9)는 0.692다. Class별로는 Person·Motorcycle·Bus·Traffic Light에서 TriFuse가, Bicycle·Car·Stop Sign에서 다른 model이 더 높은 값을 보였다.

## 한계와 연구 방향

Haze-Aware Dehazing의 첫 번째 한계는 **classifier dependency**다. 잘못된 haze type prediction은 적합하지 않은 dehazer 선택으로 이어지고, 최종 복원 결과를 악화시킬 수 있다.

두 번째 한계는 **synthetic-to-real gap**이다. 합성 training data가 실제 대기 상태와 scene의 복잡성을 모두 포함하지 못하면, synthetic benchmark에서의 성능이 real image에 그대로 이어지지 않을 수 있다.

강의는 향후 방향으로 여러 haze type을 처리하는 unified method와 computational expense가 낮은 model을 제시한다. Unified method는 type별 model 선택에 대한 의존성을 줄이려는 방향이고, 효율화는 실제 vision pipeline에서의 적용 비용과 연결된다.
