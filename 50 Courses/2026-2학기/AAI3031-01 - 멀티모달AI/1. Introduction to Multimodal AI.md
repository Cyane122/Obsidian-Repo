> [!abstract] 핵심
> 현실의 사건은 여러 신호를 만든다. [[Multimodal AI]]는 서로 다른 modality를 **Representation → Alignment → Fusion**의 흐름으로 연결해, 단일 신호만으로는 하기 어려운 추론과 판단을 수행한다.

## Artificial Intelligence의 기본 구조

**Artificial Intelligence(AI)** 는 인간의 지능이 필요한 일을 수행하는 computational system을 만드는 분야다. AI system은 input information을 useful output으로 변환하며, 다음 능력 가운데 하나 이상을 수행한다.

- **Perceive**: 환경을 보고 듣는다.
- **Learn**: data에서 pattern을 학습한다.
- **Understand**: language와 information을 해석한다.
- **Reason / Predict**: 결론이나 prediction을 만든다.
- **Act / Generate**: action을 선택하거나 새로운 content를 생성한다.

지능적인 판단은 다음 흐름으로 설명할 수 있다.

    Observe → Interpret → Decide → Act

예를 들어 사람이 도로를 건널 때는 자동차·보행자·신호등을 관찰하고, 안전한지를 해석한 뒤, 기다릴지 건널지 결정하고 행동한다. Machine이 문제를 해결하는 방식은 사람이 조건과 동작을 직접 지정하는 **Explicit Rules**와 example에서 pattern을 배우는 **Machine Learning**으로 구분할 수 있다.

- Explicit Rules: IF suspicious pattern → SPAM, ELSE → NOT SPAM
- Machine Learning: spam·normal email example을 학습해 새로운 email을 분류

두 방식 모두 input을 받아 model 또는 rule을 거쳐 useful output을 만든다는 공통 구조를 가진다.

## The Real-World Problem

- 한 사건에서 여러 signal이 나온다.
  - 예: 도로를 지나는 자동차 → camera feed, 차량 소리, LiDAR, navigation map, sensor signal
- 단일 정보는 상황을 신뢰성 있게 이해하기에 충분하지 않을 수 있다.
- 판단할 때 생각할 점
  - 어떤 signal을 신뢰할 것인가?
  - 그 signal은 언제 실패할 수 있는가?
  - 다른 signal은 이를 보완하거나 반박하는가?

## Why Multimodal AI?

- 전통적인 AI는 보통 하나의 정보 유형에 특화된다.
  - Computer Vision, NLP, Speech AI, Video Understanding, Sensor AI
- 그러나 현실 세계는 하나의 정보원만으로 주어지는 경우가 드물다.
- 핵심 생각
  - 현실은 multimodal이다.
  - 지능 시스템은 heterogeneous information을 통합하는 mechanism이 필요하다.

## What is Multimodal AI?

**Multimodal AI**는 여러 modality에서 온 정보를 처리하고, 표현하고, 연결하고, 추론하는 AI system이다.

- **Perceive**: 각 정보원을 인식한다.
- **Align**: 서로 다른 정보원에서 대응하는 부분을 찾는다.
- **Reason**: 여러 정보원을 근거로 판단한다.

> [!note] 구분
> Multimodal AI는 여러 AI model을 단순히 붙여 놓는 방식이 아니다. 서로 다른 형식의 정보를 의미 있게 상호작용할 수 있는 표현으로 만드는 일이 중심이다.

## Understanding Modality

**Modality**는 정보를 관찰하거나 표현하는 서로 다른 channel 또는 form이다. 같은 현실을 서로 다른 관점에서 보여 준다.

| Modality | Typical data | 특성·예시 |
| --- | --- | --- |
| Vision | image, pixel | photograph, spatial structure, high-dimensional, local relationship |
| Text | word, document | question, sequential/symbolic, discrete token, semantic meaning |
| Audio | waveform, spectrogram | speech, temporal signal, frequency, prosody |
| Video | frame + time | human activity, motion, long-range temporal dependency |
| Sensor | measurement, signal | temperature, IMU, sampling rate, noise, missing value |
| 3D / Spatial | point cloud, depth | LiDAR |
| Structured Data | table, event | patient record |

## Why Are Modalities Different?

- Vision: 공간 구조와 시각적 의미를 가진다.
- Text: 순서가 있는 이산 token으로 의미를 표현한다.
- Audio: 시간·주파수·억양 정보가 중요하다.
- Video: 공간 구조와 시간 변화, motion을 함께 다룬다.
- Sensor: 연속적인 수치 신호이며 물리 제약, noise, 결측이 있다.

따라서 image의 pixel, text의 token, audio의 waveform은 바로 비교할 수 없다. Multimodal system에는 modality별 **Representation Learning**, modality 사이의 **Alignment**, 정보의 **Fusion**이 필요하다.

## The Multimodal Pipeline

```text
Observe → Represent → Align → Fuse → Reason → Act
```

- **Observe**: camera, microphone, sensor, document 등에서 입력을 받는다.
- **Represent**: raw input을 embedding으로 바꾼다.
- **Align**: 같은 대상·사건·시점을 가리키는 정보를 연결한다.
- **Fuse**: 필요한 정보를 하나의 representation 또는 decision으로 결합한다.
- **Reason / Act**: 답을 만들고, 예측·경보·제어로 이어 간다.

### 예시: Image + Question

- Image: 자전거 옆에 앉은 dog
- Question: “What is beside the bicycle?”
- 필요한 과정
  1. image → visual representation
  2. question → language representation
  3. bicycle과 image 속 객체를 alignment
  4. multimodal reasoning → **Dog**

## Three Core Concepts

### 1. Representation

- 각 modality가 상호작용하기 전에 shared computational form으로 바뀌어야 한다.
- raw input은 learned representation, 즉 embedding으로 encoding된다.
- embedding
  - raw data를 continuous geometric space의 dense vector로 옮긴 표현
  - 의미가 비슷한 입력은 가깝게, 다른 입력은 멀게 놓이도록 학습한다.
- 예시
  - “cat” text, cat image, cat sound는 modality가 달라도 같은 개념을 나타내면 가까운 embedding이 될 수 있다.
- [[Word Embedding]]은 텍스트를 vector로 표현하는 관련 사례다.

### 2. Alignment

- **Multimodal Alignment**: modality 사이의 correspondence를 학습하는 과정
- 질문: “한 modality의 무엇이 다른 modality의 무엇을 가리키는가?”
- alignment 수준
  - semantic: image의 객체 ↔ text의 단어
  - temporal: video frame ↔ audio 구간 또는 event
- 어려운 이유
  - continuous/discrete 표현의 차이
  - frame rate, token 길이, sampling rate의 차이
  - 공간 구조와 추상화 수준의 차이
  - noise와 missing information
- [[Learning Transferable Visual Models From Natural Language Supervision|CLIP]]은 image-text 쌍을 [[Contrastive Learning]]으로 정렬한 사례다.

### 3. Fusion

**Multimodal Fusion**은 여러 modality에서 얻은 정보를 하나의 unified representation 또는 decision space로 결합하는 과정이다. Representation이 각 modality를 계산 가능한 형태로 만들고 Alignment가 서로 대응하는 요소를 찾는다면, Fusion은 그 정보를 실제 추론이나 prediction에 어떻게 함께 사용할지를 결정한다.

modality $m$의 input을 $x_m$, encoder를 $E_m$이라고 하면 각 representation은 다음처럼 나타낼 수 있다.

$$z_m = E_m(x_m)$$

Fusion function $\phi$는 여러 representation이나 prediction을 결합하고, task head $g$는 최종 output을 만든다.

$$h_{fuse} = \phi(z_1, z_2, \ldots, z_M), \qquad \hat{y}=g(h_{fuse})$$

Fusion의 핵심 차이는 $\phi$가 pipeline의 어느 지점에 적용되는가에 있다.

#### Early Fusion: Input-Level Integration

raw input 또는 low-level feature를 deep processing 이전에 결합한다.

    Modality A input ─┐
                             ├─ Concatenate / Joint Input ─ Model ─ Output
    Modality B input ─┘

예를 들어 synchronized sensor value를 하나의 feature vector로 이어 붙이거나, 서로 크기를 맞춘 low-level feature를 joint input으로 만들 수 있다.

- **장점**
  - 구조가 단순하고 하나의 model에서 end-to-end learning을 수행하기 쉽다.
  - 초기 단계부터 modality 사이의 관계를 함께 학습할 수 있다.
- **제약**
  - image, text, audio처럼 shape와 sampling rate가 크게 다른 raw input은 바로 합치기 어렵다.
  - modality별 전용 처리가 충분히 이루어지기 전에 결합하면 고유 구조가 손실될 수 있다.
  - time synchronization과 feature scale을 맞추는 preprocessing이 중요하다.
  - 특정 modality가 누락되면 joint input의 구조 자체가 달라질 수 있다.

#### Intermediate Fusion: Representation-Level Interaction

각 modality를 전용 encoder로 먼저 encoding한 뒤, 얻어진 representation을 interaction layer에서 결합한다.

    Image ─ Vision Encoder ─ Visual Embedding ─┐
                                                                ├─ Interaction Layer ─ Task Head
    Text  ─ Language Encoder ─ Text Embedding ─┘

interaction layer에는 concatenation, gating, bilinear interaction, cross-modal attention 등을 사용할 수 있다. Image-question 예시에서는 question의 token representation이 visual region 가운데 어느 부분을 참고해야 하는지 cross-attention으로 계산할 수 있다.

- **장점**
  - vision의 spatial structure, text의 sequential structure처럼 modality별 특성을 encoder가 먼저 처리한다.
  - 여러 층에서 세밀한 cross-modal interaction을 학습할 수 있다.
  - Representation과 Alignment 결과를 task-specific reasoning에 직접 연결하기 좋다.
  - 현대 multimodal model에서 가장 널리 사용되는 방식이다.
- **제약**
  - 여러 encoder와 interaction layer 때문에 computation과 memory cost가 크다.
  - modality별 token이나 feature 수가 많으면 attention cost가 빠르게 증가할 수 있다.
  - training 중 특정 modality에 지나치게 의존하는 modality dominance가 생길 수 있다.
  - missing modality를 처리하려면 masking, modality dropout, 대체 representation 같은 별도 설계가 필요하다.

#### Late Fusion: Decision-Level Integration

각 modality가 독립적으로 prediction을 만든 뒤 score, probability 또는 decision을 최종 단계에서 결합한다.

    Image ─ Vision Model ─ Prediction ─┐
                                                    ├─ Average / Weighted Sum / Voting ─ Final Decision
    Audio ─ Audio Model ─ Prediction ─┘

결합 방법에는 평균, weighted sum, majority voting, confidence 기반 선택 등이 있다. 예를 들어 fire detection에서 vision model의 smoke probability와 sensor model의 temperature-based probability를 합쳐 최종 경보를 결정할 수 있다.

- **장점**
  - modality별 model을 독립적으로 개발·교체·검증할 수 있어 modularity가 높다.
  - 일부 modality가 없거나 품질이 낮을 때 남은 prediction만으로 결정을 만들기 쉽다.
  - 각 modality의 prediction을 따로 확인할 수 있어 decision 해석이 비교적 쉽다.
- **제약**
  - 최종 prediction 이전에는 modality가 서로 정보를 주고받지 않는다.
  - 한 modality의 정보가 다른 modality의 의미를 바꾸는 세밀한 관계를 학습하기 어렵다.
  - “자전거 옆에 무엇이 있는가?”처럼 image와 question을 함께 보아야만 답할 수 있는 과제에는 제한적이다.

#### 세 방식 비교

| 방식 | 결합 대상 | 결합 위치 | 강점 | 주요 제약 |
| --- | --- | --- | --- | --- |
| Early Fusion | raw input 또는 low-level feature | modality별 deep processing 이전 | 단순한 joint learning | scale·shape·sampling 차이, modality 고유 구조 손실 |
| Intermediate Fusion | modality별 learned representation | encoder 이후 interaction layer | 깊은 cross-modal interaction, 구조 보존 | 높은 계산 비용, modality dominance |
| Late Fusion | score, probability, prediction | 독립 model의 decision 이후 | modularity, missing modality 대응 | 세밀한 상호작용 제한 |

#### Fusion이 활용하는 정보 관계

- **Complementary information**: 각 modality가 서로 다른 측면을 제공한다.
  - 야간 도로에서 camera는 객체의 형태와 위치를, LiDAR는 거리와 depth를, audio는 시야 밖 차량의 접근을 알려 준다.
- **Redundant information**: 여러 modality가 같은 사건을 독립적으로 확인한다.
  - camera에서 smoke가 보이고 temperature sensor도 급격한 상승을 감지하면 fire 판단의 신뢰도가 높아진다.
- **Contextual information**: 한 modality가 다른 modality의 모호성을 줄인다.
  - image만으로 사람의 동작이 애매할 때 audio나 주변 text가 상황의 의미를 좁힐 수 있다.
  - video frame의 동일한 움직임도 “문을 여는 소리”와 함께 관찰되면 event를 더 구체적으로 해석할 수 있다.

#### Fusion 방식 선택 기준

1. **필요한 interaction의 깊이**: 객체와 단어처럼 세밀한 대응이 중요하면 Intermediate Fusion이 적합하다.
2. **입력의 동기화 정도**: sampling rate와 time step이 잘 맞는 sensor stream은 Early Fusion을 적용하기 쉽다.
3. **Missing modality 가능성**: 일부 input이 자주 빠진다면 Late Fusion이나 missing-aware Intermediate Fusion이 유리하다.
4. **계산 자원**: token-level interaction이 많을수록 Intermediate Fusion의 비용이 커진다.
5. **Modularity와 해석 가능성**: modality별 독립 성능과 contribution을 분리해 보려면 Late Fusion이 편리하다.
6. **Task 특성**: 한 modality만으로도 개별 prediction이 가능하면 Late Fusion을 사용할 수 있지만, 두 modality의 관계 자체가 답이라면 representation-level interaction이 필요하다.

## Application Landscape

Multimodal AI는 low-level perception에서 high-level reasoning과 action으로 이어지는 여러 system에 사용된다.

| 영역 | 대표 사례 | 핵심 기능 |
| --- | --- | --- |
| Low-level perception | Image Enhancement, Restoration, Dehazing | noise 제거, deblurring, reconstruction, visual quality와 signal fidelity 개선 |
| Environmental understanding | Intelligent Baby Monitoring, Fire & Smoke Detection | activity·anomaly 감지, scene interpretation, early warning |
| Agentic system | Agent-Based Fire Monitoring | continuous perception–decision loop와 response strategy 연결 |
| Human behavior | Human Action Recognition, Aggressive Behavior Monitoring | temporal behavior modeling, multimodal sensor 해석, context-aware classification |
| Industrial·autonomous system | Industrial Anomaly Detection, Road Hazard Recognition | multisensor pattern 분석, deviation 감지, predictive monitoring |

구체적인 system은 다음처럼 구성될 수 있다.

- **Intelligent Baby Monitoring**: smart camera의 영상을 받아 motion을 계산하고, control chart로 abnormal breathing이나 motion pattern을 감지해 alert를 보낸다.
- **Fire & Smoke Detection**: visual cue와 environmental signal로 fire scene을 실시간 해석하고 조기 경보를 만든다.
- **Agent-Based Fire Monitoring**: object detection, person counting, flammable material recognition, fire expansion monitoring, evacuation monitoring을 여러 agent가 나누어 수행하고 결과를 공유한다.
- **Human Action Recognition**: video의 temporal pattern이나 sensor signal을 이용해 structured human motion을 해석한다.
- **Industrial Anomaly Detection**: 여러 sensor의 operational pattern에서 정상 상태를 벗어난 deviation을 찾아 system reliability를 예측한다.

## 한계

- **Noise와 missing modality**: 입력 품질이 낮거나 modality 일부가 없으면 representation과 decision이 불안정해진다.
- **Alignment error**: 서로 다른 modality의 객체·시점·의미를 잘못 연결하면 fusion 이후의 오류가 커질 수 있다.
- **Computational cost**: 여러 encoder와 interaction layer를 사용하므로 시간과 memory 비용이 증가한다.
- **Bias와 reliability**: 편향된 training data와 불균형한 modality 품질은 결과의 신뢰성을 낮춘다.
