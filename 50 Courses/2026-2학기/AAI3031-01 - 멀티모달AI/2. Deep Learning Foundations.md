## Deep Learning Foundations
- Deep Learning is a way for computers to learn patterns from data using neural networks with multiple layers.
- So, Data -> Learn Patterns -> Make Predictions.

### Three Basic Ideas
1. Learns from data instead of relying only on manually designed rules.
2. Learns useful representations from simple to complex patterns.
3. Uses multiple layers to gradually transform the input into a useful output.
-> Deep Learning learns useful patterns and representations from data.

### Branches
- AI is the biggest concept.
	- Making computers perform tasks that normally need human intelligence.
		e.g. Face recognition, Voice assistants, Chess-playing computers.
- ML is the branch of AI.
	- Teaching computers to learn from examples and make decisions.
		e.g. Spam mail prediction
- DL is the branch of ML.
	- A type of ML that uses neural networks to learn complex patterns automatically.
		e.g. Recognizing faces, handwritten numbers, or objects in images

### Why Do We Need Deep Learning?
- Tradtional Approach: Handcrafted Features
	- Humans -> manually choose useful features
	- Features -> may work well for simple problems
	- But complex data can contain patterns that are difficult to define manually.
	- Designing features becomes difficult as data becomes more complex.
- Deep Learning
	- Learns useful features automatically from data.
	- Can learn simple -> complex patterns through multiple layers.

### How Does Deep Learning Works?
- DL automatically learns features from raw data through multiple hidden layers, gradually transforming them into meaningful representations for prediction.
- At the core of DL are neural networks, which learn these patterns through interconnected layers.
## How Neural Networks Learn
### Neural Network
- Neural Network: a model that learns patterns from data.
	- made of connected neurons arranged in layers.
	- Each layer processes information and passes it to the next layer.
	- During training, the network learns how strongly neurons should be connected.
- Three main parts:
	- Input layer: receives the data
	- Hidden layer: learn patterns
	- Output layer: produces the result.

### The Artificial Neuron
- Neuron: the basic building block of a neural network.
	- receives inputs
	- gives input a weight, adds a bias
	- produces output
- Artificial Neuron = Perceptron

#### Main Components
- Inputs ($x$): information coming in
- Weights ($w$): importance given to each input
- Bias ($b$): helps adjust the result
- Weighted Sum: combines the inputs
- Output ($z$): result passed to the next layer
$$ z = \displaystyle \sum_i^n w_ix_i + b$$
