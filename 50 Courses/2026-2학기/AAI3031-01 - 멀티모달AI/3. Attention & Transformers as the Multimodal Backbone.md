> [!abstract] 핵심
> Attention은 Query에 관련된 정보를 찾아 Value를 가중합하는 연산이다. Self-Attention은 같은 입력의 element 사이의 관계를, Cross-Attention은 서로 다른 입력 사이의 관계를 계산한다. Transformer는 Attention, Positional Encoding, Feed-Forward Network 등을 결합하며, modality별 입력을 embedding sequence로 변환해 text·image·audio·video를 처리할 수 있다.

## Attention Mechanism

[[Attention]]은 입력의 여러 element에 서로 다른 weight를 부여해 현재 Query에 필요한 정보를 결합하는 Neural Network의 mechanism이다. Embedding이 입력을 vector로 표현한다면, Attention은 vector들이 어떤 정보를 서로 참고할지 계산한다.

예를 들어 “What did the boy kick?”라는 question에서는 boy의 위치와 football이 중요하다. 같은 image에서도 “Where is the boy?”를 물으면 필요한 정보가 달라진다. Attention은 입력 전체를 같은 비중으로 처리하지 않고 Query와 context에 따라 정보의 contribution을 조절한다.

### Context와 Relationships

한 element의 의미는 주변 정보와의 관계에 따라 달라진다. Football image의 boy, ball, field를 함께 보면 사람과 물체의 관계나 activity를 해석할 수 있다.

- **Local Relationship**: 가까운 token 또는 image region 사이의 관계
- **Long-Range Relationship**: 멀리 떨어진 token, region 또는 time segment 사이의 관계
- **Contextual Representation**: 다른 element의 정보를 반영해 갱신한 representation

Attention에서 “중요하다”는 것은 해당 Query의 output에 얼마나 기여하는지를 뜻한다. 모든 task에 공통인 고정 순위는 아니다. Text의 article이나 function word도 task와 context에 따라 유용할 수 있다.

### Attention Weight와 Model Parameter

**Attention Weight**는 Value를 결합할 때 사용하는 비중이다. Softmax 기반 Attention에서 한 Query에 대응하는 weight의 합은 $1$이다.

$$o_i=\sum_{j=1}^{n}\alpha_{ij}v_j,\qquad \sum_{j=1}^{n}\alpha_{ij}=1$$

- $o_i$: Query $i$의 output representation
- $\alpha_{ij}$: Query $i$가 Key $j$에 부여한 weight
- $v_j$: Key $j$와 짝을 이루는 Value

큰 weight를 가진 Value는 output에 더 많이 기여한다. 작은 weight의 Value도 weighted sum에 참여할 수 있다.

> [!note] Dynamic Weight
> Attention Weight는 training으로 학습한 projection parameter를 사용해 현재 입력에서 계산한다. Training으로 갱신되는 $W_Q,W_K,W_V$와 입력마다 달라지는 Attention Weight를 구분해야 한다.

## Soft Attention과 Hard Attention

| 관점 | Soft Attention | Hard Attention |
| --- | --- | --- |
| 정보 선택 | 여러 element에 continuous weight 부여 | 하나 또는 소수의 element 선택 |
| 결합 방식 | Value의 weighted sum | 선택한 element의 정보를 중심으로 처리 |
| 선택하지 않은 정보 | 낮은 weight로 남을 수 있음 | 보통 제외하거나 거의 사용하지 않음 |
| 예시 | traffic light·pedestrian·vehicle을 서로 다른 비중으로 반영 | traffic light region을 선택해 집중 |

교차로에서 Soft Attention은 신호등에 큰 weight를 주면서 보행자와 주변 차량도 함께 고려할 수 있다. Hard Attention은 신호등처럼 특정 region을 선택하고 필요하면 다른 region을 추가로 선택한다.

Transformer의 표준 Scaled Dot-Product Attention은 Softmax를 이용하는 Soft Attention이다. Causal Mask로 미래 position을 제외하는 것은 허용된 position 가운데 하나를 선택하는 Hard Attention과는 다른 처리다.

## Saliency Detection과 Attention

**Saliency Detection**은 image에서 시각적으로 두드러지는 region을 찾는 작업이다. Contrast, motion, 객체의 특성 또는 learned visual cue를 바탕으로 **Saliency Map**을 만들 수 있다.

**Attention Mechanism**은 Query와 관련된 input representation을 찾아 model 내부에서 정보를 결합한다. 눈에 잘 띄는 region과 특정 question에 답하는 데 필요한 region은 다를 수 있다.

| 관점 | Saliency Detection | Attention Mechanism |
| --- | --- | --- |
| 관심 대상 | 시각적으로 눈에 띄거나 중요한 region | 현재 Query와 관련된 정보 |
| 대표 입력 | image 또는 video | text, image, audio 등 representation |
| 대표 출력 | pixel·region별 Saliency Map | Query별 Attention Weight와 weighted representation |
| 계산 기준 | visual contrast, motion, learned saliency cue | Query와 Key의 관련도 |
| 정보 사용 | map을 분석하거나 region 선택에 활용 | weights로 Value를 결합 |
| application | visual saliency prediction, eye-tracking 관련 분석 | NLP, captioning, multimodal interaction |

Football image에서 Saliency Map은 boy와 ball을 강조할 수 있다. “What did the boy kick?”라는 Query의 Attention도 ball을 강조할 수 있지만, 강조하는 이유와 계산 역할은 다르다. Saliency Detection도 설정에 따라 task의 영향을 받을 수 있으므로 두 개념을 절대적인 task-independent / task-dependent 구분으로 볼 수는 없다.

## Self-Attention

[[Self-Attention]]은 같은 input sequence에서 Query, Key, Value를 만들고 element 사이의 관계를 계산한다. 각 element는 같은 sequence의 다른 element 정보를 참고해 자신의 representation을 갱신한다.

Text에서는 word·subword token의 관계를, image에서는 patch의 관계를, audio에서는 time segment의 관계를 처리할 수 있다. Mask를 사용하는 경우 각 Query가 참조할 수 있는 position은 제한된다.

### Query, Key, Value

Input embedding matrix를 $X\in\mathbb R^{n\times d_{model}}$이라고 하면 다음과 같이 계산한다.

$$Q=XW_Q,\qquad K=XW_K,\qquad V=XW_V$$

| 표현 | 역할 | 직관 |
| --- | --- | --- |
| Query(Q) | 필요한 정보를 찾는 기준 | “어떤 정보를 찾는가?” |
| Key(K) | Query와의 관련도를 계산하는 표현 | “어떤 특징으로 매칭되는가?” |
| Value(V) | 관련도에 따라 실제로 결합할 정보 | “어떤 내용을 전달하는가?” |

$W_Q,W_K,W_V$는 training으로 학습하는 서로 다른 projection matrix다. Q, K, V가 같은 input에서 나오더라도 같은 vector일 필요는 없다.

### Scaled Dot-Product Attention

[[Scaled Dot-Product Attention]]은 Query와 Key의 dot product를 scale한 뒤 Softmax로 normalize하고 Value를 가중합한다.

$$S=\frac{QK^\top}{\sqrt{d_k}},\qquad
A=\operatorname{Softmax}(S),\qquad O=AV$$

따라서 전체 식은 다음과 같다.

$$\operatorname{Attention}(Q,K,V)
=\operatorname{Softmax}\left(\frac{QK^\top}{\sqrt{d_k}}\right)V$$

| 기호 | Shape | 의미 |
| --- | --- | --- |
| $Q$ | $n\times d_k$ | Query matrix |
| $K$ | $n\times d_k$ | Key matrix |
| $V$ | $n\times d_v$ | Value matrix |
| $S$ | $n\times n$ | Query-Key score |
| $A$ | $n\times n$ | row별 Attention Weight |
| $O$ | $n\times d_v$ | contextual output |

$K^\top$는 Key matrix의 transpose다. $QK^\top$의 $(i,j)$ 값은 Query $i$와 Key $j$의 dot product이며, Softmax는 각 Query의 row에 적용한다.

1. **Score Calculation**: 각 Query를 모든 허용된 Key와 비교한다.
2. **Scaling**: $d_k$가 커질수록 dot product의 크기가 커질 수 있으므로 $\sqrt{d_k}$로 나눈다.
3. **Normalization**: [[Softmax]]로 score를 weight로 변환한다.
4. **Weighted Sum**: 각 weight와 대응하는 Value를 곱해 합한다.

Scaling은 큰 score로 Softmax가 saturation되어 gradient가 작아지는 문제를 완화한다. 정의와 계산식은 [Vaswani et al.(2017), §3.2.1](https://arxiv.org/html/1706.03762v7#S3.SS2.SSS1)에 제시되어 있다.

### Attention Score와 Weight 계산 예제

한 Query의 **scaling 이후 score**가 $s=[2.1,0.4,1.0]$이면 다음과 같다.

$$\operatorname{Softmax}(s)
=\frac{[e^{2.1},e^{0.4},e^{1.0}]}{e^{2.1}+e^{0.4}+e^{1.0}}
\approx[0.6598,0.1205,0.2196]$$

따라서 Attention output은 다음과 같다.

$$o\approx0.6598v_1+0.1205v_2+0.2196v_3$$

설명용으로 $v_1=[1,0]$, $v_2=[0,1]$, $v_3=[1,1]$을 사용하면 다음과 같다.

$$o\approx0.6598[1,0]+0.1205[0,1]+0.2196[1,1]
\approx[0.8795,0.3402]$$

Output은 하나의 Value를 그대로 선택한 결과가 아니라 여러 Value를 비중에 따라 결합한 representation이다.

## Cross-Attention

**Cross-Attention**은 한 input에서 Query를, 다른 input에서 Key와 Value를 만들어 정보를 연결한다. Text question이 image region을 참고하거나 Decoder가 Encoder output을 사용하는 경우가 이에 해당한다.

Query input을 $X_A\in\mathbb R^{n_A\times d_A}$, information source를 $X_B\in\mathbb R^{n_B\times d_B}$라고 하면 다음과 같다.

$$Q=X_AW_Q,\qquad K=X_BW_K,\qquad V=X_BW_V$$

$$O_A=\operatorname{Softmax}\left(\frac{QK^\top}{\sqrt{d_k}}\right)V$$

Projection 이후 Q와 K의 dimension은 모두 $d_k$이어야 한다. Attention matrix의 shape는 $n_A\times n_B$이고, output의 position 수는 Query input의 $n_A$다. Input sequence의 길이는 서로 달라도 된다.

### Self-Attention과 Cross-Attention 비교

| 관점 | Self-Attention | Cross-Attention |
| --- | --- | --- |
| Q의 출처 | 현재 sequence | 한 input 또는 Decoder state |
| K·V의 출처 | Q와 같은 sequence | 다른 input 또는 Encoder output |
| 대표 역할 | sequence 내부의 관계 계산 | 서로 다른 representation 사이의 정보 전달 |
| 예시 | 같은 문장의 token 관계, 같은 image의 patch 관계 | text question이 image region을 참조 |
| Attention matrix | $n\times n$ | $n_A\times n_B$ |
| 공통 계산 | score, scaling, Softmax, weighted sum | score, scaling, Softmax, weighted sum |

Self / Cross의 구분은 **Q와 K·V의 출처**에 따른다. 서로 다른 modality를 하나의 sequence로 이어 붙여 Self-Attention을 수행할 수도 있고, 같은 modality의 서로 다른 sequence를 Cross-Attention으로 연결할 수도 있다.

### Text와 Image의 Interaction

“What is the person doing?”라는 question과 달리는 사람의 image가 주어졌다고 하자.

- Text Encoder는 question token을 representation으로 변환한다.
- Vision Encoder는 image의 region 또는 patch를 representation으로 변환한다.
- Text representation이 Query를, visual representation이 Key와 Value를 제공한다.
- Query가 person의 동작과 관련된 visual information을 가져온다.
- Task head 또는 Decoder가 answer를 만든다.

이때 text의 position별 representation은 question에 필요한 visual information을 포함하게 된다. 반대 방향의 Cross-Attention도 설계할 수 있지만 한 번의 계산이 자동으로 양방향 정보를 모두 갱신하는 것은 아니다.

## Positional Encoding

[[Positional Encoding]]은 token의 순서나 input element의 위치를 representation에 제공한다. Content만 이용하는 Self-Attention은 element의 위치를 자체적으로 구분하지 못하므로 position information을 추가해야 한다.

“A car is in front of the tree.”와 “A tree is in front of the car.”는 비슷한 단어를 사용하지만 관계의 방향이 다르다. Token의 위치는 이러한 의미 차이를 표현하는 데 필요하다.

$$h_i=e_i+p_i$$

- $e_i$: position $i$의 content embedding
- $p_i$: position information
- $h_i$: Transformer에 제공할 input representation

Position information에는 fixed sinusoidal encoding이나 learned positional embedding 등을 사용할 수 있다. Text에서는 token order, image에서는 patch의 spatial position, audio에서는 time position, video에서는 spatial·temporal position이 중요하다.

## Multi-Head Attention

[[Multi-Head Attention]]은 여러 projection으로 만든 Attention head를 병렬로 계산한 뒤 output을 결합한다. 각 head는 서로 다른 representation subspace의 관계를 학습할 수 있다.

$$\operatorname{head}_i
=\operatorname{Attention}(QW_i^Q,KW_i^K,VW_i^V)$$

$$\operatorname{MultiHead}(Q,K,V)
=\operatorname{Concat}(\operatorname{head}_1,\ldots,\operatorname{head}_h)W^O$$

- $h$: head의 수
- $W_i^Q,W_i^K,W_i^V$: head별 projection parameter
- Concat: 각 head의 output을 feature dimension에서 연결
- $W^O$: 결합한 output을 model dimension으로 변환하는 projection

Football image에서 어떤 head는 person과 ball의 관계를, 다른 head는 scene context를 반영할 수 있다. 이는 설명용 직관이며 “Head 1은 반드시 boy, Head 2는 반드시 ball을 본다”처럼 사람이 역할을 고정하는 것은 아니다. 계산 구조는 [Vaswani et al.(2017), §3.2.2](https://arxiv.org/html/1706.03762v7#S3.SS2.SSS2)에 따른다.

## Transformer Architecture

[[Transformer]]는 Attention과 Feed-Forward Network 등을 layer로 쌓아 sequence representation을 처리하는 architecture다. 원래의 Transformer는 [[Encoder-Decoder]] 구조이며, Encoder와 Decoder에 서로 다른 역할의 Attention을 사용한다.

### Encoder

Encoder는 input sequence를 context를 반영한 representation sequence로 변환한다.

| Component | 역할 |
| --- | --- |
| Input Embedding | token을 numerical vector로 변환 |
| Positional Encoding | 순서·위치 정보를 반영 |
| Multi-Head Self-Attention | input token 사이의 관계를 계산 |
| Feed-Forward Network | 각 position의 feature를 추가 변환 |
| Residual Connection + Layer Normalization | representation과 gradient의 흐름, training 안정성 지원 |

Original Transformer의 Encoder block에는 Self-Attention sub-layer와 Feed-Forward sub-layer가 있다. 각 sub-layer의 output에는 [[Residual Connection]]과 [[Layer Normalization]]을 적용한다.

$$\operatorname{LayerNorm}(x+\operatorname{Sublayer}(x))$$

**Feed-Forward Network(FFN)**는 같은 transformation을 각 position에 독립적으로 적용한다. Attention이 position 사이에서 정보를 교환한다면 FFN은 각 position의 feature를 변환한다.

$$\operatorname{FFN}(x)=\operatorname{ReLU}(xW_1+b_1)W_2+b_2$$

이 식과 Normalization의 위치는 original Transformer의 구조다. 다른 Transformer variant에서는 activation이나 Normalization의 배치가 달라질 수 있다. [Vaswani et al.(2017), §3](https://arxiv.org/html/1706.03762v7#S3).

### Decoder

Decoder는 Encoder의 representation과 이미 주어진 output token을 사용해 다음 token을 예측한다.

| Component | 역할 |
| --- | --- |
| Output Embedding + Positional Encoding | 이전 output token과 position을 표현 |
| Masked Multi-Head Self-Attention | 현재 position까지의 token만 참조 |
| Encoder-Decoder Cross-Attention | Encoder output에서 필요한 정보 가져오기 |
| Feed-Forward Network | Decoder representation 변환 |
| Residual Connection + Layer Normalization | 각 sub-layer의 정보 흐름과 안정성 지원 |
| Linear + Softmax | vocabulary의 next-token probability 계산 |

Cross-Attention에서 Q는 Decoder representation, K·V는 Encoder output에서 나온다.

### Causal Mask와 Shifted Target

**Causal Mask**는 미래 token을 참조하지 못하도록 Attention score를 제한한다.

$$A=\operatorname{Softmax}\left(\frac{QK^\top}{\sqrt{d_k}}+M\right)$$

현재까지 허용한 position에는 $M_{ij}=0$, 미래 position에는 $M_{ij}=-\infty$를 적용한다. Softmax 이후 미래 position의 weight는 $0$이 된다.

Target sequence가 “A bird can fly”라면 training input과 prediction target은 다음처럼 한 position씩 어긋난다.

| Position | Decoder input | Prediction target |
| --- | --- | --- |
| 1 | BOS | A |
| 2 | A | bird |
| 3 | bird | can |
| 4 | can | fly |
| 5 | fly | EOS |

**BOS**는 sequence 시작, **EOS**는 sequence 끝을 표시하는 special token이다. Shift와 Causal Mask를 함께 사용하면 정답 token을 미리 보고 같은 token을 출력하는 정보 누출을 방지한다.

Training에서는 정답의 이전 token을 제공하므로 여러 position을 병렬로 계산할 수 있다. Autoregressive inference에서는 이미 생성한 token을 사용해 다음 token을 순차적으로 생성한다.

### Transformer Architecture Family

| 구조 | 주요 구성 | 대표 역할·예시 |
| --- | --- | --- |
| Encoder-only | bidirectional Self-Attention | input understanding, [[BERT]] |
| Decoder-only | causal Self-Attention | autoregressive generation, [[GPT]] |
| Encoder-Decoder | Encoder Self-Attention, Decoder causal Self-Attention, Cross-Attention | translation, sequence-to-sequence generation |

모든 Transformer model이 Encoder와 Decoder를 모두 가지는 것은 아니다. Attention을 중심으로 한 공통 구조를 task에 맞게 변형한다.

### RNN과 Transformer

[[Recurrent Neural Network|RNN]]은 previous hidden state를 다음 time step에 전달한다. Transformer의 Self-Attention은 허용된 position 사이의 관계를 직접 계산하므로 긴 거리의 정보를 더 짧은 경로로 연결할 수 있다.

| 관점 | RNN | Transformer |
| --- | --- | --- |
| sequence 처리 | previous state에 의존하는 순차 계산 | Attention을 통한 position 간 계산 |
| training 병렬화 | 같은 sequence 내부의 순차 의존성 | 여러 position의 계산을 병렬화 가능 |
| 먼 position의 정보 | 여러 time step을 거쳐 전달 | global attention에서는 직접 참조 가능 |
| sequence order | recurrence가 order를 반영 | 별도 position information 필요 |
| 긴 sequence의 비용 | time step 수와 함께 증가 | standard dense Attention의 score 수가 quadratic하게 증가 |

병렬화 가능성이 항상 더 낮은 computation cost를 뜻하지는 않는다. 특히 video처럼 token 수가 많은 입력에서는 Attention의 비용이 커진다.

## Transformers Across Modalities

Modality마다 raw input의 형식은 다르지만, 작은 unit으로 나누어 embedding sequence로 변환하면 Transformer의 공통 연산을 적용할 수 있다.

| Modality | Input Unit | Representation | 필요한 position information |
| --- | --- | --- | --- |
| Text | word, subword, character token | token embedding | sequence order |
| Image | patch 또는 visual region | patch·region embedding | spatial position |
| Audio | short frame, segment, acoustic feature | audio embedding | time position |
| Video | frame별 patch 또는 spatiotemporal unit | video embedding | spatial + temporal position |

### Text: Tokens

Text를 Tokenization으로 나누고 각 token을 embedding으로 변환한 뒤 position information을 반영한다.

“unbelievable”은 설명용으로 “un + believe + able”로 나눌 수 있다. 실제 subword 분할은 tokenizer의 vocabulary와 rule에 따라 다르며 Morphological Analysis의 결과와 반드시 일치하지는 않는다.

### Image: Patches

Image를 일정한 크기의 patch로 나누고, 각 patch를 Flatten한 뒤 projection으로 embedding을 만든다.

$$N_{patch}=\frac{H}{P}\times\frac{W}{P}$$

$H,W$는 image의 height·width, $P$는 square patch의 한 변이며 두 dimension이 $P$로 나누어떨어진다고 가정한다.

$$224\times224,\quad P=16
\quad\Rightarrow\quad14\times14=196\text{ patches}$$

RGB patch 하나를 Flatten하면 $16\times16\times3=768$개의 값이 된다. Projection 이후 embedding dimension은 architecture에 따라 정한다. Classification용 special token을 추가하면 전체 sequence 길이는 patch 수보다 많아질 수 있다.

### Audio: Segments

Audio는 시간에 따라 변하는 waveform이다. Short frame 또는 segment로 나누거나 spectrogram feature를 계산한 뒤 encoder·projection으로 audio embedding을 만든다.

Time position을 보존해야 word와 sound event가 언제 발생했는지 구분할 수 있다. Speech Recognition에서는 generated text token이 관련 audio segment를 Cross-Attention으로 참고할 수 있다.

### Video: Spatial and Temporal Tokens

Video에는 frame 내부의 spatial structure와 frame 사이의 temporal change가 함께 있다. Frame별 patch를 embedding으로 변환하고 위치와 time order를 제공해야 객체와 action의 변화를 해석할 수 있다.

각 frame에서 $N$개의 patch를 만들고 $T$개 frame을 사용하면 단순한 구성의 visual token 수는 $TN$이다. Frame 수를 늘리면 temporal information이 풍부해지는 동시에 Attention cost가 증가한다.

## Transformers for Multimodal AI

### Vision + Language

Image와 text를 각각 encoding하고 서로 필요한 정보를 교환하도록 연결한다.

- **Visual Question Answering(VQA)**: “What color is the car?”의 Query가 car region을 참조해 “Red”라는 answer를 만든다.
- **Image Captioning**: generated word마다 관련 visual information을 사용한다.
- **Image-Text Retrieval**: text description에 맞는 image 또는 image에 맞는 text를 검색한다.

Paired image-text data는 modality의 의미 관계를 학습하는 근거가 된다. Task와 architecture에 따라 Cross-Attention 또는 Shared Embedding Space의 similarity를 사용할 수 있다. 모든 retrieval model에 Cross-Attention이 필요한 것은 아니다.

### Audio + Language

Audio embedding과 text representation을 연결해 speech와 language 사이의 관계를 학습한다.

| Task | 입력·출력 관계 |
| --- | --- |
| Speech Recognition | spoken audio를 written transcript로 변환 |
| Speech Translation | spoken audio의 내용을 다른 language의 text로 변환 |
| Audio Captioning | sound event를 language description으로 표현 |
| Speech Generation | text를 조건으로 speech를 생성 |

Speech Recognition에서는 Decoder의 text Query가 필요한 audio segment의 K·V를 참고할 수 있다. 반대로 text가 speech generation의 조건이 될 수도 있다.

### Video + Language

Video의 spatial·temporal representation과 text를 연결한다.

- **Video Captioning**: 여러 frame의 action과 event를 sentence로 설명
- **Video Question Answering**: question과 관련된 frame·region을 사용해 answer 생성
- **Video Search**: text description에 대응하는 clip 검색
- **Temporal Localization**: “When does the person throw?”처럼 event의 time interval 식별

Image-question task에는 spatial relation이 중요하고, video-question task에는 event의 발생 시점과 순서까지 필요하다.

### Shared Embedding Space와 Cross-Modal Interaction

[[Multimodal AI]]에서 **Shared Embedding Space**는 modality별 representation의 의미를 비교할 수 있도록 alignment한 공간이다. 서로 대응하는 image, text, audio를 가깝게 놓도록 학습할 수 있다.

| 개념 | 역할 |
| --- | --- |
| Modality-specific Encoder | raw input의 고유 구조를 처리하고 representation 생성 |
| Shared Embedding Space | modality 사이의 의미·similarity 비교 |
| Self-Attention | 현재 sequence 내부에서 필요한 정보 결합 |
| Cross-Attention | 다른 representation source의 정보를 Query에 맞게 사용 |
| Task Head / Decoder | classification, retrieval, answer, generated sequence 등 output 생성 |

같은 architecture family를 사용한다는 것은 core operation을 여러 modality에 적용할 수 있다는 뜻이다. Modality별 preprocessing, encoder, training objective와 학습된 parameter까지 모두 동일하다는 뜻은 아니다.

## Practical Limitations

| 문제 | 원인·영향 |
| --- | --- |
| Training Data | 충분한 규모의 paired·aligned data가 필요하며 pairing 오류는 잘못된 관계를 학습하게 함 |
| Data Quality | noise, missing information, 잘못된 timestamp·description이 representation 품질을 낮춤 |
| Preprocessing | tokenization, patch extraction, audio feature, video frame sampling을 modality별로 설계해야 함 |
| Computation | 긴 sequence에서 Attention의 computation과 memory 사용량 증가 |
| Alignment | spatial·temporal·semantic correspondence가 어긋나면 cross-modal 이해가 어려워짐 |

Standard dense Self-Attention은 $n$개 Query와 $n$개 Key를 비교하므로 score matrix가 $n\times n$이다. Feature dimension을 고정하면 token 수를 두 배로 늘릴 때 score entry 수는 네 배가 된다. Cross-Attention의 score matrix는 $n_A\times n_B$다.

특히 video는 frame과 patch 수가 함께 증가하므로 token 수 관리가 중요하다. 큰 dataset과 계산 자원만으로 정확한 cross-modal relationship을 보장할 수는 없으며 data quality, alignment, preprocessing을 함께 고려해야 한다.
