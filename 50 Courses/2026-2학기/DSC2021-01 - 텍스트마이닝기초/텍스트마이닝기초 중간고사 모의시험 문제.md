## I. 객관식 — 각 2점

### 1. 데이터의 형태
이메일의 발신자·수신자·날짜와 자유 형식 본문을 함께 고려할 때 가장 적절한 설명은?

① 모든 부분이 동일한 표 구조를 따르므로 구조화 데이터다.
② 일부 필드에 구조가 있고 자유 형식 내용도 있으므로 반구조화 데이터로 볼 수 있다.
③ 문자로 작성된 데이터는 언제나 완전한 비구조화 데이터다.
④ 반구조화 데이터는 텍스트 마이닝에 사용할 수 없다.

### 2. 정보 검색과 텍스트 마이닝
두 작업의 주된 목적을 올바르게 연결한 것은?

① 질의와 관련된 문서 반환 — 정보 검색 / 리뷰에서 반복되는 불만 패턴 발견 — 텍스트 마이닝
② 질의와 관련된 문서 반환 — 토픽 모델링 / 리뷰에서 반복되는 불만 패턴 발견 — 정보 검색
③ 두 작업 모두 기존 문서의 위치를 찾는 것만을 목표로 한다.
④ 텍스트 마이닝은 텍스트 본문을 분석하지 않고 메타데이터만 처리한다.

### 3. LDA
LDA에 관한 설명으로 옳은 것은?

① 문서마다 하나의 정답 토픽 라벨이 반드시 주어져야 한다.
② 토픽 하나는 여러 문서의 작성 시각으로만 표현된다.
③ 문서는 여러 토픽의 혼합이며, 토픽은 단어의 분포로 표현된다.
④ 문서의 단어 순서만 보존하면 토픽을 학습할 필요가 없다.

### 4. 자연어의 분석 수준
“여기 좀 춥네요.”를 상황에 따라 “창문을 닫아 주세요.”라는 요청으로 해석하는 데 가장 직접적으로 관련된 수준은?

① Phonetics  ② Morphology  ③ Syntax  ④ Pragmatics

### 5. Stemming과 Lemmatization
옳은 설명은?

① Stemming 결과는 반드시 사전에 있는 단어다.
② Lemmatization은 모든 단어의 마지막 두 글자를 제거한다.
③ Stemming은 규칙에 따른 축약으로 비단어가 나올 수 있고, Lemmatization은 어휘·품사 정보를 활용해 사전형을 찾는다.
④ 두 방법은 어떠한 단어에서도 항상 같은 결과를 낸다.

### 6. 불용어 제거
감성 분석의 전처리 정책으로 가장 적절한 것은?

① 빈도가 높은 단어는 과제와 관계없이 전부 제거한다.
② 부정 표현 등 기능어가 판단에 영향을 주는지 확인한 뒤 과제에 맞게 제거 목록을 정한다.
③ 불용어 제거는 문서의 어순을 완전히 보존하는 기법이다.
④ 불용어 목록은 모든 언어와 도메인에서 동일하다.

### 7. 감성 사전
AFINN과 Bing의 차이를 올바르게 설명한 것은?

① AFINN은 정수 감성 점수를, Bing은 positive/negative 범주를 제공한다.
② AFINN과 Bing 모두 8개 감정 범주만 제공한다.
③ Bing은 WordNet synset마다 객관성 점수를 제공한다.
④ AFINN은 단어의 강도를 표현하지 않고 긍정/부정 두 범주만 제공한다.

### 8. NRC
NRC 사전과 결합했을 때 한 token이 여러 행으로 나타나는 이유로 가장 적절한 것은?

① 모든 문서 ID가 사라지기 때문이다.
② NRC가 각 단어의 철자를 무작위로 바꾸기 때문이다.
③ 단어의 문서 빈도를 계산하기 때문이다.
④ 같은 단어가 joy, positive, trust 등 여러 category에 속할 수 있기 때문이다.

### 9. Tidy text의 join
token table에 `inner_join(lexicon, by = "word")`를 적용했을 때 가장 적절한 설명은?

① 사전에 없는 token도 반드시 감성 점수 0을 부여받고 결과에 남는다.
② 모든 token이 정확히 한 행씩 남는다.
③ 사전에 매칭되는 token만 남으며, 사전의 매칭 행 수에 따라 token 행이 늘어날 수도 있다.
④ 원문에서 불용어만 제거한다.

### 10. Unigram BoW
소문자화·문장부호 제거 후 두 문장 “Dog bites man.”, “Man bites dog.”를 같은 vocabulary의 unigram count vector로 표현하면?

① 의미가 다르므로 반드시 다른 vector가 된다.
② 단어별 빈도가 같으므로 같은 vector가 된다.
③ 첫 단어만 비교하므로 비교할 수 없다.
④ 문법 분석 결과가 자동으로 vector에 포함된다.

### 11. Word2Vec
입력과 예측 대상의 연결이 올바른 것은?

① Skip-gram: 주변 단어 → 중심 단어 / CBOW: 중심 단어 → 주변 단어
② 두 방법 모두 document ID → 문서의 단어
③ 두 방법 모두 corpus의 공기행렬 자체만을 출력한다.
④ Skip-gram: 중심 단어 → 주변 단어 / CBOW: 주변 단어 → 중심 단어

### 12. FastText
기본 Word2Vec lookup 방식과 비교했을 때 FastText의 장점은?

① 학습된 character n-gram 정보를 결합해 OOV 단어의 vector를 생성할 수 있다.
② 철자가 비슷한 단어는 실제 의미도 항상 같다고 보장한다.
③ 단어의 vector는 모든 문장에서 반드시 달라진다.
④ subword를 사용하므로 계산·메모리 비용이 언제나 더 작다.

## III. 계산·코드 해석 — 각 6점

### 21. Word n-gram
다음 문장을 소문자화하고 문장부호만 제거한 뒤, whitespace 기준으로 token화합니다. 불용어는 제거하지 않습니다.

`The food was really good.`

(a) 모든 bigram을 순서대로 쓰세요. (2점)  
(b) 모든 trigram을 순서대로 쓰세요. (2점)  
(c) 일반적으로 n이 커질 때 얻는 장점 하나와 불리한 점 하나를 쓰세요. (2점)

### 22. 사전 기반 감성 계산
token화가 끝난 한 문서의 token은 다음과 같습니다. 반복 token은 각각 세고, 표에 없는 단어는 제외합니다. 부정어·어순 처리는 하지 않습니다.

`good, good, horrible, movie, awesome`

이 문제에서는 다음의 작은 사전만 사용합니다.

| word | AFINN value | Bing sentiment |
| --- | ---: | --- |
| good | +3 | positive |
| horrible | -3 | negative |
| awesome | +4 | positive |

(a) AFINN 합계와 계산식을 쓰세요. (2점)  
(b) Bing을 positive=+1, negative=-1로 계산한 합계와 계산식을 쓰세요. (2점)  
(c) AFINN 총점 0인 문서를 무조건 “감정이 전혀 없는 문서”라고 해석하면 안 되는 이유를 쓰세요. (2점)

### 23. R 코드와 Document–Term Matrix
`filtered_words`는 불용어 제거까지 완료된 다음 table입니다.

| id | word |
| ---: | --- |
| 1 | good |
| 1 | good |
| 1 | movie |
| 2 | bad |
| 2 | movie |

아래 코드의 빈칸을 채우세요.

```r
wide <- filtered_words %>%
  count(____, ____) %>%
  pivot_wider(
    names_from = ____,
    values_from = ____,
    values_fill = 0
  )
```

(a) 빈칸 네 개를 순서대로 쓰세요. (2점)  
(b) 최종 table을 열 순서 `id, bad, good, movie`로 쓰세요. (3점)  
(c) `values_fill = 0`의 역할을 설명하세요. (1점)

### 24. Count, Binary, TF
전처리가 끝난 corpus와 vocabulary가 다음과 같습니다.

```text
D1: good good movie
D2: bad movie
Vocabulary: [good, bad, movie]
```

(a) D1과 D2의 count vector를 쓰세요. (2점)  
(b) D1과 D2의 binary vector를 쓰세요. (2점)  
(c) TF=count/문서의 전체 token 수로 정의할 때 두 TF vector를 쓰세요. (2점)

### 25. TF-IDF
다음 세 문서만 corpus로 사용합니다. 불용어 제거를 포함한 추가 전처리는 하지 않습니다.

```text
D1: cat cat dog
D2: cat bird
D3: bird fish
```

이 문제에서는 `TF=count/문서 token 수`, `IDF=log10(N/df)`, `TF-IDF=TF×IDF`이며 smoothing·추가 정규화는 없습니다. `log10(3)=0.4771`, `log10(3/2)=0.1761`을 사용하세요.

(a) cat과 dog의 df를 각각 구하세요. (2점)  
(b) D1에서 cat과 dog의 TF-IDF를 각각 구하세요. 소수 넷째 자리까지 쓰세요. (2점)  
(c) D1에서 더 높은 TF-IDF를 갖는 단어가 cat과 dog 중 무엇인지, 그 이유를 설명하세요. (2점)

### 26. CBOW와 Softmax
문장 `the king rules`에서 문맥은 the, rules이고 정답 중심 단어는 king입니다. 입력 embedding은 다음과 같습니다.

```text
v_the   = [0.0, 1.0]
v_rules = [1.0, 0.0]
```

문맥은 평균으로 결합합니다. 전체 vocabulary는 `[the, king, rules]`이고, 별도의 출력 vector는 다음과 같습니다.

```text
u_the   = [0.0, 0.0]
u_king  = [1.0, 1.0]
u_rules = [2.0, 2.0]
```

후보 w의 score는 `u_w · h`, 확률은 `exp(score)/전체 vocabulary의 exp(score) 합`입니다. `exp(0)=1`, `exp(1)=2.718`, `exp(2)=7.389`를 사용하세요.

(a) 평균 문맥 vector h를 구하세요. (1점)  
(b) the, king, rules의 score를 순서대로 구하세요. (2점)  
(c) 현재 p(king | context)를 소수 셋째 자리까지 구하세요. (2점)  
(d) 현재 가장 높은 확률의 단어와 학습 시 확률을 높여야 할 정답 단어를 각각 쓰세요. (1점)

## IV. 서술형 — 각 4점

### 27. 분석 목적과 pipeline
쇼핑몰이 “고객이 어떤 제품 속성에 불만을 느끼는지” 알고 싶어 합니다. 다음 두 조건을 충족하는 분석 계획을 4~6문장으로 쓰세요.

(a) 적절한 분석 과제를 정하고, 문서 전체의 긍정·부정 점수만으로는 부족할 수 있는 이유를 설명하세요. (2점)  
(b) 수집 → 전처리 → 특징 표현 → 분석 → 해석·평가의 흐름을 제시하고, 평가 후 앞 단계로 돌아갈 수 있는 이유를 쓰세요. (2점)

### 28. 부정 표현과 전처리
두 리뷰 `The food is good.`, `The food is not good.`를 분석합니다.

(a) not을 불용어로 제거하고 unigram count vector를 만들 때 발생하는 문제를 설명하세요. (2점)  
(b) 이를 줄일 전처리 정책 하나와 특징 설계 방법 하나를 제안하고, 각각 왜 도움이 되는지 쓰세요. (2점)

### 29. NRC 결과 해석
한 리뷰를 NRC와 결합한 뒤 joy=3, trust=3, positive=4를 얻었습니다.

(a) 세 값을 합쳐 “서로 다른 감성 단어가 정확히 10개 있다”고 말할 수 없는 이유를 설명하세요. (2점)  
(b) 이 결과만으로 감정 강도를 확정하기 어려운 이유와, 결과를 해석할 때 확인할 사항 하나를 쓰세요. (2점)

### 30. 표현 선택과 Feature Engineering
형태 변화가 많고 학습 vocabulary에 없는 신조어도 포함된 리뷰를 분류하려고 합니다.

(a) 기본 Word2Vec lookup과 FastText 중 적절한 출발점을 고르고, 선택 이유와 한계 하나를 설명하세요. (2점)  
(b) 기본 표현 외에 추가할 특징 하나를 제안하고, feature selection, transformation, creation, extraction 중 어떤 작업으로 설명할지 근거를 쓰세요. 설명이 타당하면 여러 분류를 허용합니다. (2점)
