> 사전 기반 감성 분석은 문맥·반어·부정·도메인 차이에 약하다. **Naïve Bayes**는 클래스 사전확률에 클래스별 단어 우도를 곱하며, **SVM**은 문서를 벡터로 바꿔 클래스 사이의 마진이 큰 결정경계를 찾는다.

## Lexicon 기반 감성 분석의 한계

사전 방식은 positive·negative·neutral 등으로 표시된 단어의 점수를 합산해 전체 감성을 판정할 수 있다. 라벨 데이터 없이 빠르게 적용할 수 있지만 고정된 단어 점수에 의존한다.

| 한계 | 예시 |
| --- | --- |
| 문맥 | cold가 온도면 중립, 사람의 태도면 부정일 수 있음 |
| 부정·반어 | not good은 good과 다르고, “Oh great, another Monday.”는 great만 보면 긍정으로 오판하기 쉬움 |
| 도메인 | 금융에서 bullish는 상승 전망, 의료에서 positive test result는 질병 검출을 의미할 수 있음 |

지도학습은 감성이 표시된 예시에서 특징과 라벨의 관계를 학습한다. 대표적인 방법은 Naïve Bayes와 SVM이다. 라벨링 비용과 도메인 변화, 기존 표현이 전달하는 정보의 한계가 있다.

## Conditional Probability

$$
P(A\mid B)=\frac{P(A\cap B)}{P(B)},\qquad P(B)>0.
$$

$B$가 일어났다는 조건에서 표본공간을 $B$로 좁히고, 그중 $A$까지 성립하는 비율을 구한다. 조건이 없는 $P(A)$와 조건이 있는 $P(A\mid B)$는 서로 다른 모집단에서 계산한다.

| 예시 | 조건부 표본공간과 결과 |
| --- | --- |
| 공정한 주사위에서 짝수가 나왔을 때 6 | {2,4,6} 중 1개, $1/3$ |
| 동전 두 번 중 적어도 한 번 앞면일 때 두 번 모두 앞면 | {HH,HT,TH} 중 HH, $1/3$ |
| 동전 세 번 중 적어도 한 번 앞면일 때 정확히 두 번 뒷면 | TTT를 뺀 7개 중 HTT,THT,TTH, $3/7$ |
| 두 자녀가 모두 딸 | 첫째·둘째 순으로 적고 출생이 독립·동확률이면, 적어도 한 명이 딸일 때 $1/3$, 둘째가 딸일 때 $1/2$ |
| 부품 1,000개 중 불량 300개에서 비복원 추출 | 첫째 불량 $P(A)=300/1000$, 둘째 불량 $P(B\mid A)=299/999$, 둘 다 불량 $P(A\cap B)=0.3(299/999)\approx0.08979$ |

## Naïve Bayes

Bayes 정리는 관측 단어가 주어졌을 때 클래스가 맞을 확률을 구할 수 있게 한다.

$$
P(C\mid \mathbf w)=\frac{P(\mathbf w\mid C)P(C)}{P(\mathbf w)}.
$$

| 구성 | 의미 |
| --- | --- |
| Prior $P(C)$ | 단어를 보기 전 클래스 비중 |
| Likelihood $P(\mathbf w\mid C)$ | 해당 클래스에서 관측 단어들이 나올 가능성 |
| Evidence $P(\mathbf w)$ | 전체에서 관측 단어가 나올 확률 |
| Posterior $P(C\mid \mathbf w)$ | 단어를 본 뒤 계산한 클래스 확률 |

**Naïve 가정**은 클래스가 주어졌을 때 특징들이 조건부 독립이라는 뜻이다. Multinomial NB에서 문서의 단어 출현마다 $P(w_i\mid C)$를 곱한다. 반복 단어는 반복해서 곱해지며, 실제 계산은 underflow를 피해 로그를 더할 수 있다. 같은 문서를 여러 클래스에서 비교할 때 evidence는 공통이라 $\mathrm{Score}(C)=P(C)\prod_iP(w_i\mid C)$만 비교하면 된다. 확률이 필요하면 클래스 점수의 합으로 정규화한다.

### Laplace smoothing

$$
P(w\mid C)=\frac{\operatorname{count}(w,C)+1}{N_C+V}.
$$

$N_C$는 클래스 $C$의 전체 토큰 수, $V$는 훈련 vocabulary 크기다. 가령 terrible이 긍정 훈련 문서에 한 번도 없어도, 우도를 0으로 곱해 클래스 점수 전체를 지워버리는 일을 방지한다.

### 영화 리뷰 예제

- **The movie is good and amazing.** 슬라이드의 예시 count는 긍정 6건·부정 4건, $N_+=60$, $N_-=40$, $V=10$이다. 사용 단어 movie, good, amazing의 긍정 우도는 $9/70,\ 6/70,\ 5/70$, 부정 우도는 $7/50,\ 3/50,\ 2/50$이다. 사전확률 0.6과 0.4를 곱하면 점수는 약 0.0004723과 0.0001344다. 정규화한 긍정 확률은 약 0.7785로 긍정이다.
- **This movie is terrible.** 긍정 4건·부정 3건, $N_+=14$, $N_-=13$, $V=18$. terrible, movie의 우도는 긍정에서 $1/32,\ 2/32$, 부정에서 각각 $2/31$이다. 긍정 점수 $(4/7)(1/32)(2/32)\approx0.001116$, 부정 점수 $(3/7)(2/31)^2\approx0.001784$로 부정이다.

## Support Vector Machine (SVM)

SVM에서 문서 하나는 특징 공간의 점 하나다. 영화 리뷰 예시에서는 18개 vocabulary를 정하고, 단어의 출현 여부를 0/1로 나타낸 binary BoW나 단어 가중치인 TF-IDF를 사용한다. 새 문서에는 학습할 때 만든 같은 vocabulary, IDF, 전처리를 적용한다.

- **Hyperplane**은 $w^\mathsf T x+b=0$으로 정의되는 결정경계다. $w$는 특징 가중치, $b$는 경계의 위치를 조절하는 절편이다.
- **Margin**은 가장 가까운 훈련 사례와 경계 사이의 간격이다. 경계 주변의 훈련 사례인 **support vectors**가 경계를 결정한다.
- **Kernel trick**은 특징 변환 공간에서의 내적을 커널로 계산해 원래 공간에서 비선형 경계를 만들 수 있게 한다. SVM 계열은 분류 외에 회귀에도 쓰인다.
- **Decision function** $f(x)=w^\mathsf T x+b$의 부호로 클래스를 고른다. $f(x)=0$은 경계에 해당한다. 점수는 확률과 구별한다.

예제 `This movie is awesome.`에서 awesome에 해당하는 TF-IDF가 0.693이고 다른 항을 0으로 둔다. 학습한 $w_6=1.20,\ b=-0.30$이면 $f(x)=1.20(0.693)-0.30\approx0.532$이므로 긍정으로 분류한다.

## Naïve Bayes와 SVM 비교

| 기준 | Naïve Bayes | SVM |
| --- | --- | --- |
| 원리 | 확률 모델, 사전확률 × 우도 | 기하학적 분류, 최대 마진 경계 |
| 특징 관계 | 클래스 조건부 독립을 가정 | 그 독립 가정을 두지 않음 |
| 출력 | 클래스별 점수 또는 정규화한 posterior | 경계 기준의 실수 점수 및 클래스 |
| 데이터·활용 | 작은 데이터에서 빠른 baseline, 스팸·감성 분석 | 희소 고차원 특징에 선형 SVM이 유용, 감성·문서 주제 분류 |

성능 우열은 데이터·표현·정규화와 검증 결과에 따라 판단한다.
