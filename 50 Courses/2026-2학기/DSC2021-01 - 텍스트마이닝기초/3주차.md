## Text Mining with R

tidy text workflow의 핵심은 문서 자료를 token 단위의 tidy table로 바꾸고, `dplyr`와 `tidyr`로 요약·변환하는 것이다.

```text
Text data → Tidy text → Summarized text → Visualization
             ↑                    ↑
          tokenization          count / group / reshape
```

### 1. Tibble과 Tokenization

```r
library(dplyr)
library(tidyr)
library(tidytext)

text_data <- data.frame(
  id = 1:2,
  text = c(
    "I love this beautiful day! The sun is shining and birds are singing.",
    "The concert last night was absolutely magical!"
  )
)

tokenized_words <- text_data %>%
  unnest_tokens(word, text)
```

**Tibble**은 `dplyr`·tidyverse에서 사용하는 data frame의 현대적 표시 형식이다. `unnest_tokens(word, text)`는 `text` column의 문장을 word token으로 나누고 token 하나를 row 하나로 펼쳐 `word` column에 저장한다.

### 2. Stopword Removal, Stemming, Lemmatization

```r
filtered_words <- tokenized_words %>%
  anti_join(get_stopwords(), by = "word")

stemmed_words <- filtered_words %>%
  mutate(stem = SnowballC::wordStem(word, language = "en"))

lemmatized_words <- stemmed_words %>%
  mutate(lemma = textstem::lemmatize_words(word))
```

- `anti_join()`은 stopword table에 있는 단어를 제외한다.
- Stemming은 `running → run`, `happier → happi`, `studies → studi`처럼 규칙적으로 단어를 줄인다.
- Lemmatization은 `running → run`, `happier → happy`, `studies → study`처럼 사전형을 찾는다.

### 3. Word Counting과 Wide Text

```r
counted_words <- filtered_words %>%
  count(word, sort = TRUE)

lemma_counts <- lemmatized_words %>%
  count(id, lemma)

wider_text <- lemma_counts %>%
  pivot_wider(names_from = lemma, values_from = n, values_fill = 0)
```

`count(word, sort = TRUE)`는 단어별 빈도를 세어 내림차순으로 정렬한다. `pivot_wider()`는 문서-token-빈도의 long table을 문서를 row, lemma를 column으로 하는 document-term matrix 형태로 바꾼다.

## Lexicon-Based Sentiment Analysis

**Sentiment lexicon**은 단어와 그 단어의 감성 표지 또는 점수를 매핑한 사전이다. tidy text를 lexicon과 join한 뒤 문서별로 점수나 category count를 합산한다.

| Lexicon | 단위 | 표현 | 특징 |
| --- | --- | --- | --- |
| **AFINN** | word | integer score `-5`~`+5` | 감성의 극성과 강도를 함께 표현 |
| **Bing Liu Lexicon** | word | `positive` / `negative` | 간단한 이진 polarity list |
| **NRC Emotion Lexicon** | word | 2 sentiments + 8 emotions | 한 단어가 여러 category에 동시 속할 수 있음 |
| **SentiWordNet** | synset(word sense) | positive, negative, objective score | 단어 표면형이 아니라 WordNet sense별 점수 |

### AFINN

AFINN-165는 영어 단어에 `-5`에서 `+5`까지의 integer sentiment score를 부여한다. `0`은 neutral을 뜻한다.

```text
The movie was good but the ending was horrible.

good     +3
horrible -3
total     0 → Neutral
```

```r
library(textdata)
afinn <- get_sentiments("afinn")

afinn_scores <- lemmatized_words %>%
  inner_join(afinn, by = c("lemma" = "word")) %>%
  group_by(id) %>%
  summarise(sentiment = sum(value), .groups = "drop")
```

`inner_join()`은 lexicon에 없는 단어를 결과에서 제외하고, `sum(value)`는 문서의 총 sentiment score를 계산한다.

### Bing Liu Lexicon

Bing lexicon은 단어를 positive 또는 negative로 분류하며 강도 점수는 제공하지 않는다. 목록에 없는 단어는 점수 계산에서 빠진다.

```text
This product is good and awesome, but the service was terrible.

positive: good, awesome → +2
negative: terrible     → -1
total                   → +1
```

```r
bing <- get_sentiments("bing")

bing_scores <- lemmatized_words %>%
  inner_join(bing, by = c("lemma" = "word")) %>%
  mutate(sentiment_value = ifelse(sentiment == "positive", 1, -1)) %>%
  group_by(id) %>%
  summarise(sentiment = sum(sentiment_value), .groups = "drop")
```

### NRC Emotion Lexicon

NRC lexicon은 두 sentiment와 여덟 emotion을 다룬다.

- Sentiment: `positive`, `negative`
- Emotion: `anger`, `anticipation`, `disgust`, `fear`, `joy`, `sadness`, `surprise`, `trust`

각 word-category 관계는 `1`(연관 있음) 또는 `0`(연관 없음)으로 표시되며 한 단어가 여러 category에 들어갈 수 있다.

- `gift`: joy, positive, surprise, trust
- `abandon`: fear, negative, sadness, anger

```text
I was surprised and joyful to receive a gift from a trusted friend.

joy      3
positive 4
surprise 2
trust    3
```

```r
nrc <- get_sentiments("nrc")

nrc_counts <- lemmatized_words %>%
  inner_join(nrc, by = c("lemma" = "word")) %>%
  group_by(id, sentiment) %>%
  summarise(word_count = n(), .groups = "drop")

nrc_wide <- nrc_counts %>%
  pivot_wider(names_from = sentiment, values_from = word_count, values_fill = 0)
```

### SentiWordNet

[[WordNet]]은 영어 단어를 synonym set인 **synset**으로 그룹화하고 의미 관계를 기록한 lexical database다. **SentiWordNet**은 단어 자체가 아니라 각 synset에 다음 점수를 부여한다.

- `PosScore`: positive score
- `NegScore`: negative score
- `ObjScore`: objective score

$$PosScore + NegScore + ObjScore = 1$$

`bright`는 문맥에 따라 다른 synset을 가지므로 sentiment score도 달라진다.

| 문맥 | Sense | Pos | Neg | Obj |
| --- | --- | ---: | ---: | ---: |
| `a bright sunny day` | 빛을 내거나 잘 반사함 | 0.875 | 0.000 | 0.125 |
| `a bright student` | 배움이 빠르고 지적임 | 0.625 | 0.000 | 0.375 |

Python의 NLTK로는 adjective·verb·noun·adverb 순으로 synset을 탐색하고, 일치하는 sense의 positive·negative score를 문서별로 합산할 수 있다.

```python
from nltk.corpus import sentiwordnet as swn

def get_swn_scores(word):
    for pos in ("a", "v", "n", "r"):
        synsets = list(swn.senti_synsets(word, pos))
        if synsets:
            synset = synsets[0]
            return synset.pos_score(), synset.neg_score()

    synsets = list(swn.senti_synsets(word))
    if synsets:
        synset = synsets[0]
        return synset.pos_score(), synset.neg_score()
    return 0.0, 0.0
```

DataFrame에서는 각 lemma의 score를 column으로 추가한 뒤 `id`별로 positive·negative score를 합산한다.

> [!warning] 한계
> 첫 번째 synset을 바로 사용하면 문맥에 맞는 word sense를 고른다는 보장이 없다. SentiWordNet의 장점을 살리려면 POS tag과 [[Word Sense Disambiguation]]으로 적절한 synset을 선택해야 한다.

## Lexicon 방식 비교

| 관점 | AFINN | Bing | NRC | SentiWordNet |
| --- | --- | --- | --- | --- |
| 출력 | 강도를 포함한 수치 | 긍정/부정 | 감성+감정 category | sense별 긍정/부정/객관 점수 |
| 세밀함 | 중간 | 낮음 | 감정 유형에 세밀 | 의미 단위로 가장 세밀 |
| 사용 난이도 | 낮음 | 낮음 | 낮음~중간 | 높음; sense 선택 필요 |
| 주요 제약 | lexicon 밖 단어와 맥락을 무시 | 강도 차이를 표현 못 함 | category count가 감정 강도와 같지 않음 | WSD 오류와 synset 선택에 민감 |

사전 기반 방식은 빠르고 해석이 쉽지만 negation, sarcasm, domain-specific meaning, word order와 context를 충분히 반영하지 못한다. 감성 단어의 점수를 단순히 더할 때는 긍정과 부정이 서로 상쇄되어 mixed sentiment가 neutral로 보일 수 있다.
