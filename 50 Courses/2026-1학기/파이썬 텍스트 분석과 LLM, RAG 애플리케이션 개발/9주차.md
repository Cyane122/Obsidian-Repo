# 9주차 — Gemini API와 LangChain LCEL

## 학습 목표

LLM을 API로 호출하고 프롬프트·모델·출력 파서를 재사용 가능한 파이프라인으로 구성한다.

## 핵심 용어

- **API**: 프로그램 간 요청과 응답의 형식을 정의한 인터페이스.
- **API Key**: API 사용자를 식별하고 권한·사용량을 연결하는 비밀 자격 증명.
- **SDK**: 특정 API를 언어별 코드로 쉽게 호출하도록 제공하는 개발 도구 모음.
- **System Instruction**: 모델의 역할과 전역 규칙을 지정하는 지시.
- **Temperature**: 응답의 확률적 다양성을 조절하는 생성 설정.
- **Structured Output**: JSON 등 미리 정한 형식으로 반환되는 모델 출력.
- **LangChain**: LLM 앱 구성 요소를 연결하는 프레임워크.
- **LCEL**: runnable을 `|` 연산자로 연결하는 LangChain Expression Language.
- **Prompt Template**: 변수 자리를 가진 재사용 가능한 프롬프트.
- **Output Parser**: AI 메시지를 문자열·JSON 등 후속 처리 형식으로 변환하는 구성 요소.
- **Invoke / Batch**: 단일 입력 실행과 여러 입력 일괄 실행 방식.
- **Multi-step Pipeline**: 한 모델 호출의 결과를 다음 호출의 입력으로 전달하는 구조.

## 핵심 패턴

```text
Prompt Template | LLM | Output Parser
```

## 운영 주의

- API key를 노트북·Git 저장소에 직접 기록하지 않는다.
- JSON처럼 형식이 중요한 출력은 파서와 schema 검증을 함께 사용한다.
- batch는 처리량을 높이지만 rate limit을 고려해야 한다.
