# 13주차 — RAG 고도화

## 학습 목표

기본 벡터 검색의 약점을 청킹 전략, 키워드 검색, 다양성 선택, 재정렬, metadata, 출처 표시로 보완한다.

## 핵심 용어

- **Chunking Strategy**: 문서 구조와 질의 유형에 맞춰 chunk 크기·경계·overlap을 설계하는 방식.
- **BM25**: 단어 빈도와 문서 빈도, 문서 길이를 반영하는 키워드 랭킹 알고리즘.
- **Lexical Search**: 문자열·단어 일치를 중심으로 하는 검색.
- **Semantic Search**: embedding 의미 유사도를 중심으로 하는 검색.
- **Hybrid Search**: lexical search와 semantic search를 결합하는 방식.
- **Ensemble Retriever**: 여러 검색기의 결과를 가중 결합하는 retriever.
- **MMR**: 관련성과 결과 간 다양성을 함께 고려하는 선택 알고리즘.
- **`lambda_mult`**: MMR에서 관련성과 다양성의 비중을 조절하는 파라미터.
- **Reranking**: 넓게 검색한 후보를 더 정교한 모델로 다시 정렬하는 단계.
- **Contextual Compression**: 질의와 관련된 문서 또는 구간만 남기는 과정.
- **Metadata Filter**: category 등 구조화 속성으로 검색 범위를 제한하는 기능.
- **Similarity Threshold**: 관련도 기준을 넘는 문서만 반환하는 cutoff.
- **Few-shot Prompt**: 올바른 응답 예시를 포함한 프롬프트.
- **Source Attribution**: 답변과 함께 근거 문서·category를 반환하는 방식.

## 검색 기법 선택

| 상황 | 우선 고려 |
|---|---|
| 정책번호·전화번호·고유명사 | BM25 |
| 표현이 다른 같은 의미 | Vector Search |
| 두 종류가 섞임 | Hybrid Search |
| 중복 결과가 많음 | MMR |
| 정확도가 중요하고 비용 허용 | Reranking |
