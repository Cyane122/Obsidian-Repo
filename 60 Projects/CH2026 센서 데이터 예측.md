# 프로젝트 정의

생활 센서 시계열에서 여러 이진 타깃을 예측하는 경진대회 프로젝트다. 센서 parquet 집계, 시간·생활 패턴 특징, 신경망과 트리 모델, 피험자 단위 검증, OOF 앙상블과 Public Leaderboard 블렌드를 폭넓게 실험했다. 하나의 최종 모델을 고르는 작업보다 서로 다른 검증 축에서 무엇이 실제로 일반화되는지 찾는 과정에 가깝다.

# 데이터와 검증의 어려움

관측치는 시간 순서를 가지며 같은 피험자의 기록끼리 강하게 연결될 수 있다. 무작위 분할은 동일 인물의 습관과 센서 패턴을 train과 validation에 동시에 노출해 지나치게 낙관적인 결과를 만들 위험이 있다. 반대로 피험자를 통째로 떼어 두는 검증은 새로운 사람에게 일반화하는 능력을 더 엄격하게 본다.

프로젝트에서는 시간 기반 분할, 피험자 홀드아웃, 타깃별 OOF 결과와 Public LB를 함께 봤다. 이 때문에 ‘로컬 최고 모델’과 ‘공개 리더보드 최고 블렌드’는 같은 의미가 아니다. 로컬 OOF는 재현 가능한 모델 선택 근거이고, Public LB는 제한된 공개 구간에 대한 외부 신호다.

# 특징 공학

## 기본 집계와 이력

- 센서 parquet의 구간별 통계량
- 달력, 요일, 시각과 관측 이력 특징
- 피험자별 과거 패턴과 결측·활동량 정보

## 생활 리듬을 반영한 시간 특징

자정을 하루의 경계로 두면 새벽 활동과 수면이 서로 다른 날로 잘릴 수 있다. 시간축을 6시간 이동해 새벽까지 하나의 생활일로 묶고, 수면 창과 활동 구간을 나타내는 특징을 만들었다. 이는 달력 날짜보다 실제 생활 주기에 가까운 표현을 얻기 위한 선택이었다.

## 센서 의미를 반영한 특징

센서 이름을 독립적인 숫자 열로만 다루지 않고 수면, 활동, 공간 이동과 연결되는 의미 기반 요약을 구성했다. Semantic 계열과 Anchor 계열은 이런 가공 특징을 서로 다른 방식으로 사용한다. 이후 모델 스택에서 이 특징군이 로컬 OOF 상위권을 형성했다.

## 가까운 날짜의 라벨 사전확률

같은 피험자의 가까운 날짜가 유사할 가능성을 이용한 label-KNN-prior를 실험했다. 같은 사람의 근접 시점을 참고하되 검증 누출이 생기지 않도록 분할 안에서 계산해야 하는 특징이다. 친구 브랜치의 robust 특징과 결합되어 최종 Public LB 블렌드의 한 축이 됐다.

# 모델 실험

## 시퀀스 신경망 비교

동일한 교차검증 틀에서 LSTM, GRU, 단순 RNN, Transformer를 비교했다.

| 모델 | 평균 CV logloss |
|---|---:|
| LSTM | 0.642543 |
| GRU | 0.652431 |
| RNN | 0.660048 |
| Transformer | 0.666938 |

평균으로는 LSTM이 가장 낮았지만 모든 타깃에서 한 모델이 이기지는 않았다. RNN이 Q1과 Q3에서 우세해 타깃별 모델 선택을 적용했고, 평균 logloss가 약 `0.636879 → 0.634041`로 개선됐다. 이 결과는 복잡한 모델 하나보다 타깃별 데이터 특성에 맞는 선택이 더 유효할 수 있음을 보여줬다.

## 트리·스택 모델

CatBoost, LightGBM, XGBoost, Extra Trees와 로지스틱 계열을 특징군별로 조합했다. Semantic·Anchor 스택이 로컬 OOF에서 가장 강한 축이었다.

- `model_targetwise`: 약 `0.5612`
- `anchor_targetwise_selected`: 약 `0.5654`
- sensor-adjusted kernel: 약 `0.6030 → 0.5846`

이 수치들은 같은 로컬 평가 맥락에서 해석해야 하며 Public LB 값과 직접 비교할 수 없다.

## 앙상블과 블렌드

OOF 예측 상관과 타깃별 성능을 보며 보수적으로 블렌드했다. 특정 성분이 Public LB에서 좋아 보인다고 비중을 계속 올리면 어느 지점부터 성능이 나빠졌다. 따라서 단일 제출 결과에 과도하게 맞추기보다 서로 다른 오류를 내는 후보를 섞는 쪽을 택했다.

# 친구 브랜치와 실험 계보

2026-05-23 전후로 `TAE-GEON` 브랜치의 아이디어와 결과를 별도 스크립트·보고서·제출물로 받아 비교했다. 주요 기여는 6시간 이동 시간축, 수면 창, 의미 기반 센서 특징, 피험자 홀드아웃, 같은 피험자의 근접 날짜를 이용한 label-KNN-prior였다.

초기에는 친구 결과와 v3·v4 후보를 섞은 블렌드가 Public logloss 약 0.5991~0.5992를 기록했다. 이후 robust 후보들의 비중을 조정해 더 나은 제출을 찾았다.

# 최종 확인 결과

사용자가 직접 정정해 확인한 최고 Public LB 제출은 다음과 같다.

```text
blend_friend25_v3robust3125_v4knnrobust4375_submission.csv
Public logloss: 0.5974867204
```

이 이름은 친구 예측 25%, v3 robust 31.25%, v4 KNN robust 43.75%의 구성 비율을 나타낸다. 세션 중 다른 후보가 최고로 잘못 인식된 적이 있었기 때문에, 이 값은 자동 추정이 아니라 사용자 확인을 거친 최종 기록으로 남긴다.

# 진행 타임라인

## 2026-05-18 전후

기본 집계·규칙·트리 모델에 시퀀스 모델을 추가하고 동일 CV에서 비교했다. 타깃별 우승 모델을 선택하는 방식이 전체 단일 모델보다 좋아졌다.

## 2026-05-23 전후

친구 브랜치의 semantic robust와 label-KNN-prior 계열을 병합하지 않은 채 독립 실험 경로로 정리했다. Public LB 블렌드와 로컬의 피험자 일반화 검증을 병행했다.

## 2026-05-26

코드, 주요 스크립트, OOF 결과, 제출 후보, 현재 최고 점수와 실패한 방향을 다음 세션이 이어받을 수 있도록 인수인계 문서로 정리했다. 대회의 최종 마감 이후 순위는 세션 기록에서 확인되지 않는다.

# 남은 해석 과제

- Public LB에 맞춘 블렌드가 Private 구간에서도 유지됐는지 확인해야 한다.
- label-KNN-prior가 분할 밖의 라벨 정보를 보지 않는지 실험별로 재검증할 필요가 있다.
- 로컬 OOF 최고 스택과 최종 Public 제출의 차이를 타깃별로 분해하면 어떤 성분이 실제로 기여했는지 더 명확해진다.
- 여러 실험 스크립트의 공통 전처리와 평가 코드를 통합하면 재현성이 높아진다.
