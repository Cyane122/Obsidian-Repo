# 개요

`레이드 기록`은 [[아크 그리드 코어 기록장]]의 주간 입력 화면이다. 캐릭터와 레이드 난이도별로 클리어 여부, 전설·유물·고대·영웅 코어 수, 획득 골드와 더보기 비용을 기록한다.

# 입력 동작

- 코어 수를 추가하면 해당 레이드의 클리어 상태도 자동으로 켜진다.
- 코어가 0개여도 클리어만 체크해 ‘드랍 없음’ 표본을 남길 수 있다.
- 캐릭터의 아이템 레벨에 맞는 난이도만 선택할 수 있다.
- 게임의 주간 경계인 한국 시간 수요일 오전 6시에 새 주차로 넘어간다.

# 골드 집계

레이드 보상 골드에서 더보기 비용을 뺀 순골드를 계산한다. 대성당처럼 귀속 골드가 섞이는 경우는 별도 표기로 구분한다. 주간 골드 합계에는 순골드가 높은 상위 3개 레이드만 들어가지만, 코어 획득 기록 자체는 그 제한과 무관하게 계속 저장한다.
