# 개요

`원정대 동기화`는 [[아크 그리드 코어 기록장]]이 로스트아크 API에서 대표 캐릭터의 원정대 정보를 읽어 기록 대상을 갱신하는 기능이다. 세션에서는 대표 캐릭터가 속한 원정대 15명을 받아, 미리 지정한 클래스마다 아이템 레벨이 가장 높은 캐릭터를 선택했다.

# 동기화 범위

API에서 가져오는 값은 캐릭터명, 클래스와 아이템 레벨처럼 레이드 자격을 판단하는 정보다. 실제 코어 획득 기록은 브라우저 로컬 저장소에 남고 API로 전송되지 않는다. 아이템 레벨에 따라 가능한 레이드와 가장 높은 난이도를 기본값으로 고르는 데 동기화 결과를 사용한다.

# 보안 경계

로스트아크 API JWT는 서버 비밀값으로 보관하고 브라우저에 노출하지 않는다. 응답은 `no-store`로 처리하고 인증 쿠키를 만들지 않았다. 이 기능은 원정대 구성을 편하게 갱신하기 위한 것이지, 로컬 기록을 서버 계정에 동기화하는 기능은 아니다.
