# 개요

`evaluateSetting`은 [[로스트아크 기상술사 딜 최적화기]]에서 하나의 후보 세팅을 기준 세팅과 비교하는 핵심 평가 함수다. 공격력이나 치명타를 단순 합산하지 않고, 스킬마다 실제로 적용되는 배율을 구한 뒤 기준 스킬 지분으로 가중한다.

# 계산값

```text
후보 상대 딜 = Σ(기준 스킬 지분 × 후보 스킬 배율 / 기준 스킬 배율)
```

관측된 스킬 지분에는 이미 현재 보석·트라이포드·아크그리드 효과가 들어 있다. 따라서 기준 세팅의 배율을 먼저 제거하고 후보 배율을 다시 입혀야 같은 효과를 두 번 세지 않는다.

# 모델 경계

범용 공격력·추가 피해·적에게 주는 피해와 특정 스킬·상태 전용 효과를 나눠 계산한다. 재사용 대기시간, 실제 시전 빈도, 자원과 가동률은 단순 피해 배율과 같은 축으로 취급하지 않는다. 이 함수의 전제가 틀리면 모든 후보의 순위가 함께 틀어지므로, CPU와 [[GaleGPU]]가 같은 계산 의미를 공유해야 한다.
