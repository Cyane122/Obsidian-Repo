# 개요

`데이터·AI 주간 브리핑`은 한 주 동안 저장된 [[데이터·AI 데일리 브리핑]]만 읽어 반복된 흐름과 중요 항목을 묶는 주간 예약 작업이다. 별도의 웹 검색은 하지 않는다.

# 데일리와의 역할 분리

데일리는 새 사실의 발견과 출처 검증을 맡는다. 주간은 이미 저장된 자료를 압축하고, 여러 날 반복된 신호와 실제 읽기·지원·프로젝트 가치가 높은 항목을 승격한다.

# 운영

주간 보고서도 해당 주에 정상 생성된 기록이 있으면 다시 만들지 않는다. 데일리 원문에 없는 내용을 새로 보충하지 않아 두 조사 경로가 서로 다른 사실을 만드는 것을 막는다.
