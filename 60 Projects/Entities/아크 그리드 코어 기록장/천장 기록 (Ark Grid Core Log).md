# 개요

`천장 기록`은 [[아크 그리드 코어 기록장]]에서 레이드 드랍과 별도로 정가 결과를 누적하는 화면이다. 주차에 종속된 레이드 기록과 달리, 정가를 시도할 때마다 나온 코어의 등급을 한 건씩 더한다.

# 분리한 이유

레이드 드랍과 정가는 획득 조건과 표본 단위가 다르다. 둘을 같은 주간 통계에 합치면 실제 드랍 분포를 해석하기 어려워진다. 따라서 천장 결과는 유물·고대 등급별 누적 횟수와 비율을 독립적으로 보여준다.
