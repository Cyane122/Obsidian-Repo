# 개요

`확률 추정`은 [[아크 그리드 코어 기록장]]에 쌓인 코어 획득 기록을 등급별 비율로 보여주는 화면이다. 레이드 클리어 횟수와 실제 획득 코어 수를 함께 보여주되, 확률의 분모는 사용자의 정정에 따라 전체 획득 코어 수로 정의됐다.

# 계산 정의

```text
등급별 추정 비율 = 해당 등급 코어 수 / 전체 획득 코어 수 × 100
```

초기에는 ‘한 번의 클리어에서 하나 이상 나왔는가’를 기준으로 삼았지만, 이후 전설·유물·고대 코어 전체에서 각 등급이 차지하는 비율로 바뀌었다. 클리어 횟수는 확률의 직접 분모가 아니라 표본 규모를 판단하는 보조 수치로 남는다.

# 예외 표시

획득 기록이 없거나 표본이 정의되지 않는 구간은 0%로 단정하지 않고 `—`로 표시한다. 세션에서는 아이템 레벨 1720 이상 영웅 코어 확률도 같은 방식으로 처리했다.
