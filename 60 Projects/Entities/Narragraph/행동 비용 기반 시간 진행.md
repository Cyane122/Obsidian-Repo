# 정의

현실 시간이나 렌더 횟수가 아니라 이동 거리, 행동 cost, 사건 duration처럼 플레이어 행동에 부여된 비용만큼 게임 시간을 진행하는 규칙이다.

# 적용 원칙

- 이동과 사건이 반환한 시간 비용을 scheduler가 누적한다.
- decay와 예약 사건은 렌더나 실시간 timer가 아니라 scheduler tick에서 처리한다.
- 행동을 잘게 쪼갠 게임 팩이 불리해지지 않도록 개별 클릭 횟수가 아니라 의미 있는 시간 비용을 사용한다.
- snapshot과 event log에는 결과 시간뿐 아니라 시간 변화의 원인을 남긴다.
