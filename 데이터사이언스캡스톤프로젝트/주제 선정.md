## 유튜브 댓글
- 수집 수단: Youtube API << 하루 10,000 unit까지 요청 가능
	- `serach.list`: 영상 ID인듯 / 1회 요청당 100 unit 소모 / 1회당 50개 영상 조회 가능
	- `commentThreads.list`: 이게 댓글 - 1회 요청당 1 unit 소모 / 1회당 100개 댓글 수집 가능
	- `comments.list`: 이건 대댓글 - 1회 요청당 1 unit 소모 / 1회당 100개 대댓글 수집 가능
	- `videos.list`: 영상 조회인데 영상 총 조회수나 댓글 수 같은 정보 불러오는 거 / 1회 요청당 1 unit 소모 / 1회당 50개 영상 조회 가능
- PII 주의해야해서 동일 사용자 분석하고 싶으면 따로 암호화하거나 해시함수 써야할듯

## 유튜브 자막
- 공식 Youtube API
	- `captions.list`: 1회 요청당 50 unit 소모 / 자막 트랙의 존재 여부, 언어, 자동생성 여부 등을 확인할 순 있음
	- `captions.download`: 이게 문제임 / 영상 소유자 아니면 다운 불가능
- 스크립트 표시 기능: 이거로 손수 긁어오는 것도 상당히 귀찮지만 나쁘지는 않을듯
- 비공식 API (`youtube-transcript-api`, `yt-dlp`)
	- 안 되는 건 아닌데 IP 차단이나 429 에러 뜰 수도 있음
