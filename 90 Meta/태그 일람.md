# 태그 원칙

- 태그는 폴더를 가로질러 검색할 가치가 있는 축만 표현한다.
- 모든 태그는 lowercase kebab-case의 계층형 형태를 사용한다.
- 한 노트에는 2~4개를 사용한다: `domain/*` 1개, `task/*` 0~1개, `method/*` 또는 `theme/*` 1~2개.
- 논문 제목, 모델 한 개의 이름, 데이터셋, 저자, 연도는 태그로 만들지 않고 속성 또는 `[[Wikilink]]`로 표현한다.
- 새 태그는 최소 3개 이상의 노트에서 재사용될 때만 추가한다.

# Domain

| 태그 | 범위 |
|---|---|
| `#domain/machine-learning` | 특정 응용 분야에 한정되지 않는 범용 ML |
| `#domain/nlp` | 자연어 처리와 언어 모델링 |
| `#domain/multimodal` | 둘 이상의 modality를 결합하는 연구 |
| `#domain/recommender-systems` | 추천, 랭킹, 사용자-아이템 상호작용 |
| `#domain/privacy-and-safety` | 분야 독립적인 프라이버시·안전 연구 |

# Task

| 태그 | 범위 |
|---|---|
| `#task/language-modeling` | 토큰 또는 시퀀스 확률 모델링 |
| `#task/machine-translation` | 언어 간 번역 |
| `#task/text-rewriting` | 의미·속성을 제어하는 텍스트 재작성 |
| `#task/text-classification` | 텍스트 레이블 예측 전반 |
| `#task/natural-language-inference` | entailment, contradiction, neutral 판별 |
| `#task/summarization` | 요약 생성 및 관련 평가 |
| `#task/recommendation` | 사용자별 아이템 추천 또는 랭킹 |
| `#task/representation-learning` | 재사용 가능한 표현 학습 자체가 목표인 연구 |
| `#task/zero-shot-transfer` | 별도 task-specific 학습 없이 전이하는 설정 |

# Method

| 태그 | 범위 |
|---|---|
| `#method/attention` | Attention 계열 메커니즘 |
| `#method/activation-function` | Sigmoid, Tanh, Softmax 같은 활성화 함수 |
| `#method/neural-network` | 특정 세부 계열에 한정되지 않는 신경망 구조 |
| `#method/transformer` | Transformer 계열 아키텍처 |
| `#method/recurrent-neural-network` | RNN, LSTM, GRU 계열 |
| `#method/encoder-decoder` | Encoder-Decoder 구조 |
| `#method/word-embedding` | 단어 수준 분산 표현 학습 |
| `#method/contrastive-learning` | positive/negative 관계를 이용한 대조 학습 |
| `#method/collaborative-filtering` | 상호작용 기반 협업 필터링 |
| `#method/pairwise-ranking` | 쌍별 선호 비교를 이용한 랭킹 |
| `#method/tree-search` | 탐색 트리와 exploration/exploitation을 이용하는 방법 |
| `#method/differential-privacy` | 수학적 Differential Privacy 보장 |
| `#method/optimization` | optimizer와 최적화 절차 |
| `#method/normalization` | activation 또는 representation 정규화 |
| `#method/regularization` | 과적합 억제 기법 |
| `#method/sampling` | negative, noise, approximate sampling 기법 |
| `#method/matrix-factorization` | 행렬 분해 기반 표현·추천 방법 |
| `#method/dimensionality-reduction` | SVD, PCA 계열 저차원 근사 방법 |
| `#method/information-theory` | entropy, divergence, mutual information 계열 측도 |
| `#method/large-language-model` | LLM을 핵심 추론 또는 생성 모듈로 사용하는 방법 |

# Theme

| 태그 | 범위 |
|---|---|
| `#theme/privacy-preservation` | 프라이버시 누출 감소가 핵심 관심사인 연구 |
| `#theme/training-stability` | gradient, normalization 등 학습 안정성 |
| `#theme/computational-efficiency` | 시간·메모리·샘플 효율 개선 |
| `#theme/evaluation` | metric, benchmark, 평가 설계 자체가 중심인 문서 |
| `#theme/generalization` | 도메인·태스크·분포 밖 일반화 |
| `#theme/alignment` | 번역 위치 정렬이 중심인 경우 |

# Legacy normalization

| 기존 표현 | canonical 표현 | 비고 |
|---|---|---|
| `#NLP` | `#domain/nlp` | 대소문자뿐 아니라 축도 명시 |
| `#RNNs` | `#method/recurrent-neural-network` | 단수형 canonical family 사용 |
| `#Encoder`, `#encoder-decoder` | `#method/encoder-decoder` | Encoder 단독 의미면 문맥 확인 |
| `#MCTS` | `#method/tree-search` | 특정 알고리즘명은 위키링크로 유지 |
| `#LLM` | `#method/large-language-model` | 약어 태그 금지 |
| `#training-stabilty` | `#theme/training-stability` | 오탈자 수정 |
| `#noise_injection` | `#method/differential-privacy` 또는 `#method/regularization` | 목적에 따라 선택 |
| `#data_protection`, `#privacy-reserving` | `#theme/privacy-preservation` | 동일 관심사 통합 |
| `#matrix_factorization` | `#method/matrix-factorization` | underscore 금지 |
| `#ELMo`, `#CLIP`, `#GloVe`, `#word2vec` | 관련 task/method 태그 | 고유 모델명은 태그 대신 위키링크 사용 |
| `#text-generation`, `#text-analysis` | 문맥에 맞는 `task/*` | 중심 task가 아닐 때 삭제 |

# 예시

- Attention Is All You Need: `#domain/nlp #task/machine-translation #method/attention #method/transformer`
- Learning Transferable Visual Models From Natural Language Supervision: `#domain/multimodal #task/zero-shot-transfer #method/contrastive-learning #theme/generalization`
- Zero-Shot Privacy-Aware Text Rewriting via Iterative Tree Search: `#domain/nlp #task/text-rewriting #method/tree-search #theme/privacy-preservation`
- Softmax: `#domain/machine-learning #method/normalization`
- ROUGE: `#domain/nlp #task/summarization #theme/evaluation`
