# 정의

Text Mining은 대량의 텍스트에서 반복되는 패턴, 주제, 감성, 개체, 관계처럼 활용 가능한 정보를 찾는 분석 과정이다. 기존 문서를 찾아 주는 Information Retrieval과 달리, 텍스트를 분석해 새로운 요약이나 통찰을 만든다.

# 왜 필요한가

뉴스, 고객 후기, 대화, 문서처럼 사람이 모두 읽기 어려운 규모의 텍스트를 체계적으로 살피고 의사결정에 연결하기 위해 필요하다.

# 작동 원리

원문 수집, 전처리, 특징 표현, 모델링, 결과 해석과 시각화의 흐름으로 진행한다. 전처리 뒤에는 단어 빈도, [[Term Frequency–Inverse Document Frequency|TF-IDF]], [[Word Embedding]]처럼 텍스트를 비교·계산 가능한 형태로 바꾼다.

# 특징과 한계

- 데이터 마이닝, 통계, 전산언어학, 자연어 처리의 방법을 함께 사용한다.
- 결과의 의미와 유용성은 수집 범위, 전처리, 표현 방식, 평가 기준에 따라 달라진다.
- 빈도나 모델의 예측 결과만으로 원인과 인과관계를 단정할 수는 없다.
